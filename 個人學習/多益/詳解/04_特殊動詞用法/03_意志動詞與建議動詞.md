# 03_意志動詞與建議動詞 - 詳細解答

## 題目 1：建議動詞 recommend + that 子句 + 原形動詞
**答案**: C

**詳細解析**:
recommended 為建議動詞，後方接 that 子句，子句動詞須用**原形動詞**（可視為省略 should），答案為 (C) be。(A) is 為現在式，未使用原形動詞；(B) was 為過去式；(D) being 為動名詞/現在分詞形式，皆不符合建議動詞 + that 子句的固定句型。

**相關文法點**:
對應主章節「2. 句型結構」：`S + 意志/建議動詞 + that + S + (should) + 原形動詞`。

**相似題型提醒**:
be 動詞的原形一律是 **be**，無論主詞單複數皆同，是此文法點最容易考的細節之一。

## 題目 2：意志動詞 require + that 子句 + 原形動詞
**答案**: B

**詳細解析**:
require 為意志動詞，後方 that 子句省略了 that（require that every visitor (should) wear...，此處 that 已包含在句子結構中），子句動詞須用**原形動詞**，不受第三人稱單數 every visitor 影響，答案為 (B) wear。(A) wears 是加了 -s 的第三人稱單數現在式，是常見陷阱選項；(C) wearing 為現在分詞；(D) to wear 為不定詞，皆不符合公式。

**相關文法點**:
對應主章節「2. 句型結構」表格中 require 範例：「The policy requires that all employees **wear** ID badges. (不是 wears)」。

**相似題型提醒**:
這是全題型中最常見的陷阱：主詞是第三人稱單數（every visitor, he, she），但因為前面出現 require/insist/demand 等觸發詞，子句動詞仍要用原形，不可加 -s。

---

## 題目 3：形容詞 essential + that 子句 + 原形動詞
**答案**: C

**詳細解析**:
It is essential that... 為「形容詞 + that 子句」句型，子句動詞須用**原形動詞**，答案為 (C) review。(A) reviews 為第三人稱單數現在式；(B) reviewed 為過去式；(D) to review 為不定詞，皆不符合此固定句型。

**相關文法點**:
對應主章節「4. 形容詞形式 (It is + adj. + that ...)」。

**相似題型提醒**:
除了 essential，同類形容詞如 important, necessary, vital, crucial, advisable, imperative, urgent 皆適用相同規則，看到 `It is + 這些形容詞 + that` 就直接秒選原形動詞。

## 題目 4：意志/建議動詞混合句型（Part 6 短文）
**答案**: (1) B　(2) C

**詳細解析**:
(1) insists that each department ___ a detailed expense report，insist 為意志動詞，之後 that 子句動詞須用**原形動詞**，答案為 (B) submit。(A) submits 為第三人稱單數現在式是常見陷阱；(C) submitted 為過去式；(D) submitting 為現在分詞，皆不符合公式。
(2) it is advisable that managers ___ any unusual expenditures，advisable 為觸發原形動詞的形容詞，之後 that 子句動詞須用**原形動詞**，答案為 (C) discuss。(A) discusses 為第三人稱單數現在式；(B) discussed 為過去式；(D) to discuss 為不定詞，皆不符合「It is advisable that + S + 原形動詞」的句型。

**相關文法點**:
對應主章節「2. 句型結構」與「4. 形容詞形式 (It is + adj. + that ...)」。

**相似題型提醒**:
同一篇短文中可能同時出現「意志動詞觸發的 that 子句」與「形容詞觸發的 that 子句」，兩者規則相同（皆用原形動詞），但觸發詞的詞性不同（動詞 vs. 形容詞），閱讀時需辨識觸發詞本身，而非死記單一句型。

## 題目 5：意志動詞 demand + that 子句 + 原形動詞（be 動詞）
**答案**: C

**詳細解析**:
demanded 為意志動詞，之後 that 子句的動詞為 be 動詞，須用原形 **be**，答案為 (C)。(A) is 為現在式；(B) was 為過去式；(D) has been 為現在完成式，皆不符合意志動詞 + that 子句的固定句型，也不是原形動詞。

**相關文法點**:
對應主章節「2. 句型結構」表格中 demand 範例，以及 insist/request 範例中 be 動詞用法（"be，不是 is"）。

**相似題型提醒**:
凡是意志/建議動詞 + that 子句，且子句主詞後面接的是 be 動詞時，答案幾乎必為 **be**，這是最容易辨識、也最常考的固定考點。

---

## 題目 6：意志動詞 insist + that 子句用原形
**答案**: C

**詳細解析**:
`insist` 後方的 that 子句要用**原形動詞**（should 省略），被動語態同樣用原形 be ➔ **be**(C)。(A) is、(B) was、(D) were 都是變化過的形式。

**相關文法點**:
對應「2. 句型結構」：`He insisted that the meeting be held immediately.`

**相似題型提醒**:
被動語態在這個句型裡寫成 `be + p.p.`，不會是 `is + p.p.` 或 `was + p.p.`。這是最容易被語感帶偏的地方。

---

## 題目 7：建議動詞 recommend + that 子句用原形
**答案**: C

**詳細解析**:
`recommend` 後方的 that 子句一律用**原形動詞**，即使主詞是第三人稱單數也不加 -s ➔ **adjust**(C)。(A) 加了 -s；(B) 是過去式；(D) 是動名詞。

**相關文法點**:
對應「📝 多益秒殺解題技巧 1」：suggest, recommend, require, insist, demand, request 後面的 that 子句秒選原形動詞。

**相似題型提醒**:
`recommend` 不接 that 子句時可以接動名詞（recommend adjusting），但一旦出現 that，子句動詞就必須是原形。

---

## 題目 8：形容詞 imperative + that 子句用原形
**答案**: B

**詳細解析**:
`It is imperative that…` 的子句要用**原形動詞** ➔ **have**(B)，即使主詞 `every shipment` 是單數也不加 -s。(A) has 是第三人稱單數形；(C) 是過去式；(D) 是動名詞。

**相關文法點**:
對應「4. 形容詞形式 (It is + adj. + that ...)」：important, necessary, essential, vital, crucial, imperative。

**相似題型提醒**:
這組形容詞要背熟。看到 `It is + 這些字 + that`，子句動詞一律原形，主詞單複數完全不影響。

---

## 題目 9：建議動詞 propose + that 子句用原形
**答案**: B

**詳細解析**:
`propose` 後方的 that 子句一律用**原形動詞**，即使主詞 `the company` 是第三人稱單數也不加 -s ➔ **raise**(B)。(A) raises 加了 -s；(C) raised 是過去式；(D) raising 是動名詞。

**相關文法點**:
對應「1. 常見的意志動詞與建議動詞」建議／請求類：suggest, recommend, propose, request, urge, ask。

**相似題型提醒**:
同樣是 propose，接不定詞時語意不同（propose to do＝打算做）。判斷關鍵在後面接的是 that 子句還是不定詞。

## 題目 10：名詞形式 request 後的 that 子句
**答案**: B

**詳細解析**:
`request` 的**名詞形式**後面接 that 子句時，子句動詞同樣用原形 ➔ **be made**(B)。(A)、(C) 是變化形；(D) 語態不合。

**相關文法點**:
對應「3. 名詞形式也適用」：`His suggestion that the meeting be postponed was accepted.`

**相似題型提醒**:
動詞、名詞、形容詞三種形式都套用同一條規則。看到 suggestion / recommendation / requirement / request 後面的 that 子句，一樣選原形。

---

## 題目 11：意志動詞 demand + that 子句用原形
**答案**: C

**詳細解析**:
`demand` 後方的 that 子句用**原形動詞** ➔ **provide**(C)，主詞 `each contractor` 雖是單數也不加 -s。(A) 加了 -s；(B) 是過去式；(D) 是動名詞。

**相關文法點**:
對應「1. 常見的意志動詞與建議動詞」意志／命令類：insist, demand, require, order, command。

**相似題型提醒**:
`each`, `every`, `everyone` 當子句主詞時最容易讓人反射性加 -s，正是這個題型的陷阱設計。

## 題目 12：建議動詞 urge + that 子句用原形
**答案**: B

**詳細解析**:
`urge` 後方的 that 子句用**原形動詞** ➔ **extend**(B)，主詞 `the operations team` 雖是單數也不加 -s。(A) extends 加了 -s；(C) extended 是過去式；(D) extending 是動名詞。

**相關文法點**:
對應「2. 句型結構」：`S + 意志/建議動詞 + that + S + (should) + 原形動詞`。

**相似題型提醒**:
這個句型裡不會出現時態變化——因為它本質上是省略了 should 的虛擬語氣，不受主句時態影響。

---

## 題目 13：形容詞 advisable + that 子句用原形
**答案**: C

**詳細解析**:
`It is advisable that…` 的子句要用**原形動詞** ➔ **mail**(C)。(A) 是第三人稱單數形；(B) 是過去式；(D) 是動名詞。

**相關文法點**:
對應「4. 形容詞形式」：advisable 屬於這組觸發原形動詞的形容詞。

**相似題型提醒**:
此處主詞 `applicants` 是複數，原形與現在式同形，看不出差別；出題時通常會用單數主詞才能區分，要留意。

## 題目 14：意志動詞 order + that 子句被動用 be
**答案**: B

**詳細解析**:
`order` 後方的 that 子句用原形動詞，被動語態為 `be + p.p.` ➔ **be removed**(B)。(A) 是現在式被動；(C) 是過去式被動；(D) 缺少動詞形式。

**相關文法點**:
對應「1. 常見的意志動詞與建議動詞」意志／命令類的 order。

**相似題型提醒**:
主詞是複數 `all outdated manuals` 時，被動仍寫 `be removed` 而不是 `are removed`——原形不隨主詞變化。

---

## 題目 15：意志動詞 require + that 子句用原形
**答案**: B

**詳細解析**:
`require` 後方的 that 子句用**原形動詞** ➔ **present**(B)，主詞 `the treasurer` 雖是第三人稱單數也不加 -s。(A) 加了 -s；(C) 是過去式；(D) 是動名詞。

**相關文法點**:
對應「2. 句型結構」表格：`The policy requires that all employees wear ID badges.`

**相似題型提醒**:
`require` 有兩種句型：`require that + S + 原形V` 與 `require someone to do`。看到 that 就用原形，看到受詞就用 to V。
