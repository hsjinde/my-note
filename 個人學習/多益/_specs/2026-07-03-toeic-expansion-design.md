# TOEIC 教材擴展設計文檔

**日期**: 2026-07-03  
**專案**: TOEIC 多益學習教材擴展  
**目標**: 補充文法深度、新增閱讀練習、單字片語、模擬考試

---

## 1. 專案概述

### 1.1 目標
將既有的 TOEIC 文法教材擴展為完整的學習系統，包括：
- 文法章節深化與補充
- 閱讀理解練習（單句填空、段落、篇章）
- 相關單字和片語
- 練習題和詳解

### 1.2 核心方案：章節內整合
採用「方案 1：章節內整合」模式，使每個文法章節成為完整的學習單位。

---

## 2. 內容結構設計

### 2.1 現有文法體系（6 大類別，23 個章節）

| 類別 | 現有章節數 | 狀態 |
|------|----------|------|
| 01 八大詞性與句型結構 | 5 | 保留並擴展 |
| 02 動詞時態與語態 | 3 | 保留並擴展 |
| 03 動狀詞_非謂語動詞 | 4 | 保留並擴展 |
| 04 特殊動詞用法 | 3 | 保留並擴展 |
| 05 子句與假設語氣 | 4 | 保留並擴展 |
| 06 其他多益必考進階題型 | 4 | 保留並擴展 |

### 2.2 每個章節的新增內容

每個現有文法章節（如 `01_名詞與代名詞.md`）將保留原有內容，並在末尾按順序新增：

#### **第一層：秒殺公式區（新增）**
- 位置：「📝 多益秒殺解題技巧」章節下方
- 內容：新增 3-5 個額外的速記技巧、常見陷阱、出題邏輯
- 格式：
  ```
  ## 📚 補充秒殺公式
  1. [公式名稱]：[口訣或速記方法]
  2. [常見陷阱]：[如何快速識別和避免]
  3. ...
  ```

#### **第二層：相關單字和片語區（新增）**
- 位置：秒殺公式區下方
- 內容：該章節涉及的核心詞彙和片語
- 格式：按詞性或用途分類
  ```
  ## 🔤 相關單字和片語
  
  ### 名詞
  - **詞彙1** (pronunciation): 定義 | 例句
  - **詞彙2**: 定義 | 例句
  
  ### 動詞
  - **動詞1**: 定義 | 例句
  
  ### 片語
  - **片語1**: 定義 | 例句
  ```

#### **第三層：練習題區（新增）**
- 位置：單字區下方
- 數量：每章節 5 題
- 題型混合：多選單句填空、段落理解、篇章閱讀（混在一起，不分級）
- 格式：
  ```
  ## 💪 練習題（5 題）
  
  ### 題目 1：[題型] - [難度指示或來源]
  [完整題目內容，帶選項 A/B/C/D]
  
  ### 題目 2：[題型]
  [完整題目內容]
  
  ...
  
  [每題下方有簡短「答案」提示，詳細詳解見詳解資料夾]
  ```

## 3. 詳解資料夾結構

### 3.1 路徑設計
```
詳解/
├── 01_八大詞性與句型結構/
│   ├── 01_名詞與代名詞.md
│   ├── 02_動詞分類.md
│   ├── 03_形容詞與副詞.md
│   ├── 04_連接詞.md
│   ├── 05_介系詞.md
│   └── 06_五大句型.md
├── 02_動詞時態與語態/
│   ├── 01_基本時態與進行式.md
│   ├── 02_完成式.md
│   └── 03_被動語態.md
└── [其他類別] ...
```

### 3.2 詳解檔案內容
每個詳解檔案對應一章文法（例如 `詳解/01_八大詞性與句型結構/01_名詞與代名詞.md`）

**結構**：
```
# 01_名詞與代名詞 - 詳細解答

## 題目 1：[題型] - [分類]
**答案**: C

**詳細解析**:
[逐選項分析，解釋為什麼選 C，為什麼不選 A/B/D]

**相關文法點**: 
- [參考主文法章節的某個小節]

**相似題型提醒**:
- [類似的考點或常見變化]

---

## 題目 2：[題型]
[同上結構]
```

## 4. 新增內容的補充部分

### 4.1 補充缺失的文法主題
檢查後補充可能遺漏的主題（如冠詞用法、量詞等），決定：
- 新增獨立章節，或
- 融入現有章節

### 4.2 閱讀理解（本次納入實施範圍）
建立獨立資料夾：
```
閱讀理解/
├── 01_單句填空題/  (2-3 個練習檔，每檔 5-8 題)
├── 02_段落填空題/  (2-3 個練習檔)
└── 03_篇章閱讀題/  (2-3 個練習檔)
```
對應詳解存於 `詳解/閱讀理解/`

### 4.3 模擬考試（本次納入實施範圍）
建立獨立資料夾 `模擬考試/`，包含 1-2 份綜合模擬測驗（混合文法 + 閱讀），對應詳解存於 `詳解/模擬考試/`
