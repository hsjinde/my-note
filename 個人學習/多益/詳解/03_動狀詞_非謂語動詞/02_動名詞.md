# 02_動名詞 - 詳細解答

## 題目 1：單句填空 - 動詞 + 動名詞
**答案**: B

**詳細解析**:
`suggest`（建議）是必須接動名詞的動詞，看到 suggest 後方留空，直接秒選 **V-ing**。(A) revise 是原形動詞，不能直接接在 suggested 後面；(C) to revise 為不定詞，suggest 不接不定詞；(D) revised 為過去分詞，文法不通。正確答案為 **(B) revising**。

**相關文法點**:
對應主章節「2. 必須接動名詞 (V-ing) 的動詞」，suggest 屬於記憶口訣中的常見字。

**相似題型提醒**:
同類動詞 consider, recommend, avoid, enjoy, postpone/delay, finish, mind 皆固定接 V-ing，看到動詞即可秒選，不需分析句意。

## 題目 2：單句填空 - 介系詞 + 動名詞
**答案**: C

**詳細解析**:
`look forward to` 中的 to 是介系詞而非不定詞的 to，後方必須接 V-ing。(A) hear 是原形動詞；(B) heard 為過去式/過去分詞；(D) to hear 誤把 to 當作不定詞使用，皆不符合文法。正確答案為 **(C) hearing**。

**相關文法點**:
對應主章節「4. 多益常見慣用語 (接 V-ing)」，look forward to + V-ing/N 是多益必考片語。

**相似題型提醒**:
同類「介系詞 to + V-ing」片語還有 be used to, be accustomed to, object to, be committed to, be dedicated to，皆須特別留意 to 的詞性是介系詞而非不定詞標記。

---

## 題目 3：單句填空 - be worth + V-ing
**答案**: B

**詳細解析**:
`be worth + V-ing`（值得...）是固定句型，後方一律接動名詞。(A) install 為原形動詞；(C) to install 為不定詞，worth 不接不定詞；(D) installed 為過去分詞，文法不通。正確答案為 **(B) installing**。

**相關文法點**:
對應補充秒殺公式「be worth + V-ing（值得...）：固定句型，後面一律接 V-ing，不可接 to V」。

**相似題型提醒**:
注意與 `be worthy of + V-ing/N` 做對比，worthy 後面需要介系詞 of，而 worth 後面直接加 V-ing，兩者結構不同但意思相近。

## 題目 5：短文填空 - be committed to / consider + V-ing
**答案**: (1) B　(2) B

**詳細解析**:
(1) `be committed to`（致力於）中的 to 是介系詞，後方須接 V-ing，故選 **(B) reducing**。
(2) `consider`（考慮）是必須接動名詞的動詞，後方須接 V-ing，故選 **(B) using**。

**相關文法點**:
對應主章節「4. 多益常見慣用語 (接 V-ing)」中的 be committed to，以及「2. 必須接動名詞 (V-ing) 的動詞」中的 consider。

**相似題型提醒**:
短文中若同時出現「介系詞 to + V-ing」與「動詞 + V-ing」兩種考點，需分別判斷空格前方的詞性（介系詞 vs. 動詞），避免混淆成不定詞的 to。

## 題目 6：動名詞作主詞
**答案**: B

**詳細解析**:
句首缺少主詞，動詞 `requires` 是單數 ➔ 用**動名詞作主詞** **Consolidating**(B)，動名詞主詞一律視為單數。(A) 是原形動詞；(C) 是過去分詞；(D) 形式不合。

**相關文法點**:
對應「1. 動名詞作主詞」：動名詞當主詞時視為單數，後面動詞用單數形。

**相似題型提醒**:
動名詞主詞與單數動詞的搭配是隱藏考點：`Attending the conference requires…`，不是 require。

## 題目 7：postpone 後接動名詞
**答案**: C

**詳細解析**:
`postpone`（延後）是**必須接動名詞**的動詞 ➔ **scheduling**(C)。(A) 是原形；(B) 是不定詞；(D) 是過去分詞。

**相關文法點**:
對應「2. 必須接動名詞 (V-ing) 的動詞」口訣：enjoy, finish, mind, avoid, suggest, consider, postpone (delay)。

**相似題型提醒**:
與 `postpone` 同組的還有 `delay`, `practice`, `admit`, `deny`, `quit`, `risk`。這些動詞後面出現 to V 一律是錯的。

## 題目 8：介系詞 without 後接動名詞
**答案**: C

**詳細解析**:
`without` 是**介系詞**，後面遇到動詞一定變成 V-ing ➔ **finding**(C)。(A) 是原形；(B) 是不定詞；(D) 是過去分詞。

**相關文法點**:
對應「3. 介系詞後必接 V-ing」：in, on, at, of, for, with, without, by, about。

**相似題型提醒**:
介系詞後接 V-ing 是最機械的一條規則。看到空格前是介系詞，直接選 V-ing，不必判斷語意。

---

## 題目 9：by 後接動名詞表方法
**答案**: B

**詳細解析**:
`by`（藉由）是介系詞，後面接**動名詞**表達方法 ➔ **combining**(B)。(A) 是原形；(C) 是不定詞；(D) 是過去分詞。

**相關文法點**:
對應「3. 介系詞後必接 V-ing」：`By using this coupon, you get a 20% discount.`

**相似題型提醒**:
`by + V-ing`（藉由做…）與 `by + 時間`（在…之前）是同一個介系詞的兩種用法，靠後面接的是動詞還是時間來分辨。

## 題目 10：be dedicated to 後接動名詞
**答案**: B

**詳細解析**:
`be dedicated to` 中的 `to` 是**介系詞**，後面接動名詞 ➔ **bringing**(B)。(A) 是原形，那是不定詞的用法；(C) 是過去分詞；(D) 是被動不定詞。

**相關文法點**:
對應「4. 多益常見慣用語 (接 V-ing)」：be committed to / be dedicated to + V-ing/N。

**相似題型提醒**:
這組片語的 `to` 是介系詞而非不定詞，是多益最愛設的陷阱：look forward to, object to, be used to, be accustomed to, be dedicated to。

## 題目 13：recommend 後接動名詞
**答案**: C

**詳細解析**:
`recommend`（建議）後面接**動名詞** ➔ **testing**(C)。(A) 是原形；(B) 是不定詞；(D) 是過去分詞。

**相關文法點**:

**答案**: B
