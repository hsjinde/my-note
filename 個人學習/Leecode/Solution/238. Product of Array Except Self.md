## 題目描述 (中文摘要)

給定一個整數陣列 `nums`（長度 $N \geq 2$），回傳一個等長陣列 `answer`，其中 `answer[i]` 等於 `nums` 中「除了 `nums[i]` 以外」所有元素的乘積。

三個關鍵限制：

- **陣列可能含 0，也可能含負數**，所以不能假設乘積恆正或非零。
- **禁止使用除法 (Division)**，不能先算總乘積再除以自身。
- 時間必須是 $O(N)$；follow-up 進一步要求 **$O(1)$ 額外空間**（回傳的輸出陣列不計入空間複雜度）。

範例：

```
輸入：nums = [1, 2, 3, 4]
輸出：[24, 12, 8, 6]

輸入：nums = [-1, 1, 0, -3, 3]
輸出：[0, 0, 9, 0, 0]
```

## 思路總覽 (Overview & Interview Plan)

### 中文解題計畫

核心觀察：「除自身以外的乘積」可以拆成兩塊互不重疊的區間——**`i` 左邊全部的乘積**乘上 **`i` 右邊全部的乘積**。

1. **演算法選擇**：採用 **前綴積與後綴積 (Prefix Product & Suffix Product)**。
2. **具體步驟**：
   - 第一次由左往右掃描，計算 `prefix[i]` = `nums[0..i-1]` 的乘積。
   - 第二次由右往左掃描，計算 `suffix[i]` = `nums[i+1..N-1]` 的乘積。
   - `answer[i] = prefix[i] * suffix[i]`，兩段合起來剛好涵蓋除了 `nums[i]` 之外的所有元素。
   - 兩端的空區間乘積定義為 `1`（乘法單位元），故 `prefix[0] = suffix[N-1] = 1`。
3. **優化方向**：後綴積只在單次由右往左的掃描中被用到一次，因此可以壓成一個滾動變數 (rolling variable)，把額外空間降到 $O(1)$。

### English Interview Plan

For each index, return the product of every element except the one at that index, without using division and in linear time.

1. **Strategy**: Decompose the answer into a **prefix product** (everything to the left of `i`) and a **suffix product** (everything to the right of `i`). Their product covers exactly the elements we want and excludes `nums[i]` by construction, so no division is ever needed.
2. **Execution**:
   - **Base Case**: An empty range has product `1`, so `prefix[0] = 1` and `suffix[N-1] = 1`.
   - **Iterative Step**: Left-to-right, `prefix[i] = prefix[i-1] * nums[i-1]`. Right-to-left, `suffix[i] = suffix[i+1] * nums[i+1]`.
   - **Key Insight**: The suffix array is consumed exactly once during a single right-to-left pass, so it can collapse into one rolling variable — giving $O(1)$ extra space while the output array is written in place.

## 演算法詳解

暴力解是對每個 `i` 再跑一次內層迴圈把其他元素乘起來，時間是 $O(N^2)$，在 $N$ 達 $10^5$ 時必然逾時。它的浪費在於：`answer[0]` 和 `answer[1]` 的計算都掃過了 `nums[2..N-1]` 這一整段，同一段乘積被重算了 $N$ 次。

前後綴解法就是把這些重複區間的乘積「快取」下來：一次由左往右累積，一次由右往左累積，每段區間乘積只算一次。

至於另一個直覺——先求總乘積再除以 `nums[i]`——除了題目明文禁止除法之外，遇到 `0` 也會直接崩潰（除以零），必須額外統計零的個數並分三種情況討論，反而更容易寫錯。前後綴解法完全不需要對 `0` 做任何特判。

### 狀態變化 (State Transitions)

以 `nums = [1, 2, 3, 4]` 為例，`length = 4`。

1. **初始化**：`l1 = [1, 1, 1, 1]`、`l2 = [1, 1, 1, 1]`。
2. **前綴掃描**（`i` 從 1 到 3，`l1[i] = nums[i-1] * l1[i-1]`）：
   - `i=1`：`l1[1] = nums[0] * l1[0] = 1 * 1 = 1`
   - `i=2`：`l1[2] = nums[1] * l1[1] = 2 * 1 = 2`
   - `i=3`：`l1[3] = nums[2] * l1[2] = 3 * 2 = 6`
   - 得到 `l1 = [1, 1, 2, 6]`（每格是「我左邊全部的乘積」）
3. **後綴掃描**（`i` 從 2 遞減到 0，`l2[i] = nums[i+1] * l2[i+1]`）：
   - `i=2`：`l2[2] = nums[3] * l2[3] = 4 * 1 = 4`
   - `i=1`：`l2[1] = nums[2] * l2[2] = 3 * 4 = 12`
   - `i=0`：`l2[0] = nums[1] * l2[1] = 2 * 12 = 24`
   - 得到 `l2 = [24, 12, 4, 1]`（每格是「我右邊全部的乘積」）
4. **合併**：`res[i] = l1[i] * l2[i]` → `[1*24, 1*12, 2*4, 6*1] = [24, 12, 8, 6]`。

再看 $O(1)$ 版本如何用一個變數取代 `l2`。此時 `res` 已經存著前綴積 `[1, 1, 2, 6]`，令滾動變數 `right = 1`：

| 步驟 | `res[i]` 更新前的值（前綴積） | `right`（右邊乘積） | `res[i]` 更新後 | `right` 更新為 |
|---|---|---|---|---|
| `i=3` | 6 | 1 | `6 * 1 = 6` | `1 * nums[3] = 4` |
| `i=2` | 2 | 4 | `2 * 4 = 8` | `4 * nums[2] = 12` |
| `i=1` | 1 | 12 | `1 * 12 = 12` | `12 * nums[1] = 24` |
| `i=0` | 1 | 24 | `1 * 24 = 24` | （結束） |

最終 `res = [24, 12, 8, 6]`，與雙陣列版完全一致。關鍵順序是**先用 `right` 更新 `res[i]`，再把 `nums[i]` 併入 `right`**——順序顛倒的話 `nums[i]` 就會把自己乘進答案裡。

## 程式碼實作

### 版本一：前後綴雙陣列

```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        length = len(nums)
        # 全部初始化為 1：空區間的乘積是乘法單位元，
        # 這樣 l1[0] 與 l2[length-1] 不必另外特判。
        l1 = [1] * length  # l1[i] = nums[0..i-1] 的乘積
        l2 = [1] * length  # l2[i] = nums[i+1..length-1] 的乘積
        res = [1] * length

        # 從 1 開始：i=0 左邊沒有元素，若從 0 開始 nums[-1] 會取到最後一個元素而靜默算錯
        for i in range(1, length):
            l1[i] = nums[i - 1] * l1[i - 1]

        # 從 length-2 開始：i=length-1 右邊沒有元素，維持 1
        for i in range(length - 2, -1, -1):
            l2[i] = nums[i + 1] * l2[i + 1]

        for i in range(length):
            res[i] = l1[i] * l2[i]
        return res
```

### 版本二：常數額外空間

```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        length = len(nums)
        res = [1] * length

        # 第一趟：把前綴積直接寫進輸出陣列，省下 l1
        for i in range(1, length):
            res[i] = res[i - 1] * nums[i - 1]

        # 第二趟：用單一變數滾動累積右邊乘積，取代整個 l2 陣列
        right = 1
        for i in range(length - 1, -1, -1):
            # 必須先乘進答案、再把自己併入 right，
            # 否則 nums[i] 會被算進 res[i] 而違反「除自身以外」
            res[i] *= right
            right *= nums[i]
        return res
```

## 正確性說明

1. **不重複 (No Redundancy)**：`prefix[i]` 涵蓋索引 `[0, i-1]`、`suffix[i]` 涵蓋索引 `[i+1, N-1]`，兩個區間交集為空，因此沒有任何元素被乘進答案兩次。
2. **不遺漏 (Completeness)**：兩區間的聯集是 `[0, N-1] \ {i}`，恰好是「除自身以外」的完整集合；再由歸納法可證每次掃描都正確——`prefix[0] = 1` 成立，且若 `prefix[i-1]` 正確，則 `prefix[i] = prefix[i-1] * nums[i-1]` 也正確，後綴同理。
3. **邊界條件**：
   - `N = 2`：`res = [nums[1], nums[0]]`，前綴迴圈只跑一次、後綴迴圈只跑一次，正確。
   - **含單一 0**：該位置的前後綴都不含 0，答案為其餘元素乘積；其他位置必然把這個 0 乘進去，答案為 0。
   - **含兩個以上 0**：任一位置的前後綴至少涵蓋一個 0，全部輸出 0——無需特判，自然成立。
   - **含負數**：乘法本身處理符號，不影響邏輯。

## 時間複雜度分析

- **Time Complexity**：$O(N)$
  - 其中 $N$ 為 `nums` 的長度。版本一是三趟獨立的線性掃描（$3N$），版本二是兩趟（$2N$），常數項不同但同屬線性。
  - 最好與最壞情況相同，皆為 $\Theta(N)$：沒有提早結束 (early exit) 的條件，每個元素在每趟都必須被讀取一次，輸入內容（含 0 與否、正負）不影響執行步數。

---

## 空間複雜度分析

- **版本一（雙陣列）**：$O(N)$ 額外空間，需要 `l1` 與 `l2` 兩個長度為 $N$ 的輔助陣列。
- **版本二（滾動變數）**：$O(1)$ 額外空間，只用了 `right` 一個變數。
  - 依題目 follow-up 的慣例，回傳的 `res` 屬於輸出 (output)，不計入額外空間；兩個版本的輸出開銷都是 $O(N)$，差異只在輔助結構。

## 常見誤區

1. **用總乘積除以自身**：除了題目明文禁止除法之外，只要陣列含 `0` 就會發生除以零的錯誤；即使改成「統計 0 的個數再分情況討論」也得處理零個、一個、多個 0 三種分支，比前後綴解法更長也更容易漏 case。
2. **前綴迴圈的起點寫成 `range(length)`**：`i = 0` 時 `nums[i-1]` 會變成 `nums[-1]`，Python 的負索引不會拋出例外，而是**靜默取到最後一個元素**，導致整個 `l1` 錯位、答案錯誤且極難除錯。同理，後綴迴圈必須從 `length - 2` 起跳，寫成 `length - 1` 會存取 `l2[length]` 而直接 IndexError。
3. **$O(1)$ 版本裡先更新 `right` 再乘進 `res[i]`**：順序顛倒會把 `nums[i]` 自己乘進答案，`res[i]` 變成整個陣列的乘積而非「除自身以外」。務必記住「先取用、後累積」。
4. **輔助陣列初始化成 0**：`[0] * length` 會讓所有乘積歸零。空區間的乘積是 `1` 而不是 `0`，這是乘法單位元，不是隨手挑的初值。
5. **只交出雙陣列版就收工**：它時間是 $O(N)$ 沒錯，但沒有滿足 follow-up 的 $O(1)$ extra space 要求；面試時被追問「還能再省嗎」而答不出來，等同沒完成這題。

## 小結

這題是**前綴／後綴預處理 (Prefix & Suffix Precomputation)** 的入門代表題：當每個位置的答案都依賴「左邊一整段」與「右邊一整段」時，就用兩趟掃描把區間資訊快取起來，把 $O(N^2)$ 壓到 $O(N)$。

**核心觀念：**

- 把「除自身以外」拆成左右兩個互斥區間，是避開除法、也避開 0 特判的關鍵。
- 空區間的乘積是 `1`（乘法單位元），初始化正確就不需要邊界特判。
- 輸出陣列可以當成計算過程的暫存，加上滾動變數就能把輔助空間降到 $O(1)$。
