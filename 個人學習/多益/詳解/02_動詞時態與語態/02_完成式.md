# 02_完成式 - 詳細解答

## 題目 1：現在完成式（經驗 + since 過去時間點）
**答案**: C

**詳細解析**:
"since it was founded in 1998" 表示「從 1998 年成立以來」，公司在這段期間內換過三次商標，屬於「從過去到現在的經驗」，應使用**現在完成式**。故選 (C) has changed。(A) changes 現在簡單式無法表達「累積至今」的語意；(B) changed 過去簡單式僅描述單一過去動作，不符合 since 引導的持續語境；(D) will change 未來式與句意不符。

**相關文法點**:
對應第 1 節「現在完成式」中「經驗」用法，常搭配 since + 過去時間點。

**相似題型提醒**:
注意 since 子句本身用過去式（was founded），主句才用現在完成式，是常考的時態搭配組合。

---

## 題目 2：過去完成式（by the time + 過去式）
**答案**: B

**詳細解析**:
"By the time the inspector arrived" 是 by the time 加過去式子句，表示「在檢查員抵達之前」，工人已經完成的動作應使用**過去完成式**，表達「過去的過去」。故選 (B) had / fixed。(A) have / fixed 現在完成式時態層次不對；(C) will have / fixed 未來完成式與過去時間軸矛盾；(D) has / fixed 現在完成式且單複數也不一致。

**相關文法點**:
對應第 2 節「過去完成式」：by the time + 過去式子句 ➔ 主句用過去完成式。

**相似題型提醒**:
by the time 子句的動詞時態決定主句時態：子句過去式 ➔ 主句過去完成式；子句現在式 ➔ 主句未來完成式（見題目 3）。

## 題目 3：未來完成式（by + 未來時間）
**答案**: C

**詳細解析**:
"by the end of this quarter" 是明確的未來時間點，表示「到某個未來時間點之前將完成的動作」，應使用**未來完成式**。故選 (C) will have implemented。(A) implement 現在簡單式不符合語意；(B) implemented 過去式時態錯誤；(D) had implemented 過去完成式與未來時間點矛盾。

**相關文法點**:
對應第 3 節「未來完成式」：by + 未來時間 ➔ will have + p.p.。

**相似題型提醒**:
by + 未來時間點（by 2027, by next Friday, by the end of...）幾乎是未來完成式的正字標記，务必快速辨識。

## 題目 4：have been to vs. have gone to
**答案**: A

**詳細解析**:
句意為「Ms. Lopez 今年已經去過柏林兩次（人現在不在柏林，已經回來了）」，強調的是「經驗、次數」，應使用 **have/has been to**。故選 (A) has been。(B) has gone 表示「去了、人目前還在該地」，與句子強調「兩次經驗」的語意不符；(C) went 過去簡單式無法搭配 twice this year 這種累計經驗的語意；(D) is going 現在進行式不符合已發生兩次的語境。

**相關文法點**:
對應「📚 補充秒殺公式」第 2 點：have/has been to（去過，已回來） vs. have/has gone to（去了，人還在那）。

**相似題型提醒**:
這是多益經典陷阱組合，務必牢記兩者差異：been to 強調經歷，gone to 強調目前人不在此處（在目的地）。

## 題目 5：短文填空（過去簡單式 + 未來完成式）
**答案**: (1) B　(2) C

**詳細解析**:
(1) "Since the company ... last spring" 中，since 引導的子句本身須使用**過去簡單式**描述過去某個確切時間點發生的動作，搭配主句 "have decreased"（現在完成式），形成 since + 過去式，主句 + 現在完成式 的標準結構，故選 (B) introduced。(A) introduces 現在簡單式與 last spring 明確過去時間矛盾；(C) has introduced 現在完成式不可用於 since 子句本身；(D) will introduce 未來式與句意不符。
(2) "By the end of this year" 是未來時間點，表示到那時管理層將已完成政策的全面檢討，應使用**未來完成式**，故選 (C) will have conducted。(A)(D) 為現在式/現在完成式，與 by the end of this year 的未來時間點不符；(B) had conducted 過去完成式時態錯誤。

**相關文法點**:
對應第 1 節「現在完成式」（since 子句用過去式）與第 3 節「未來完成式」（by + 未來時間）。

**相似題型提醒**:
篇章題常在同一段落中混合過去簡單式（since 子句）與未來完成式（by + 未來時間），需分別依各句的時間線索個別判斷，不能套用同一時態。

## 題目 6：現在完成式（for + 一段時間）
**答案**: C

**詳細解析**:
`for more than a decade` 表示從過去持續到現在 ➔ 用現在完成式 **has worked**(C)。(A) works 是現在簡單式，無法表達持續期間；(B) worked 表示已經結束的過去；(D) will work 是未來式。

**相關文法點**:
對應「1. 現在完成式」的持續用法：常搭配 for + 一段時間、since + 過去時間點。

**相似題型提醒**:
`for` 後面接**一段時間**（for ten years），`since` 後面接**時間起點**（since 2015）。兩者都是現在完成式的標準提示。

---

## 題目 7：現在完成式（so far）
**答案**: C

**詳細解析**:
`So far`（到目前為止）代表期間尚未結束、統計持續累積 ➔ 用現在完成式 **has resolved**(C)。(A) 是現在簡單式；(B) 是過去簡單式，會把這一季講成已結束；(D) 是過去完成式。

**相關文法點**:
對應「1. 現在完成式」的多益必考關鍵字：so far / up to now。

**相似題型提醒**:
`this quarter`, `this year`, `today` 這類「尚未結束的期間」搭配的是現在完成式；`last quarter` 這種已結束的期間才用過去式。

---

## 題目 8：過去完成式（by the time + 過去式）
**答案**: C

**詳細解析**:
兩個動作都在過去，搬移**先發生**於稽核人員索取檔案 ➔ 先發生的用過去完成式 **had moved**(C)。(A) 是現在式；(B) 過去簡單式無法標示先後；(D) 是現在完成式，與過去時間軸不合。

**相關文法點**:
對應「2. 過去完成式」：`by the time + 過去式子句` 是過去完成式的固定提示。

**相似題型提醒**:
判斷法：句中有兩個過去動作時，**先發生的用 had + p.p.**，後發生的用過去簡單式。哪一個先發生要看語意，不是看句子順序。

---

## 題目 9：未來完成式（by + 未來時間）
**答案**: C

**詳細解析**:
`By the end of next month` 是未來的截止時間點，表示屆時將已完成 ➔ 用未來完成式 **will have renovated**(C)。(A) 是現在式；(B) 是過去式；(D) 是現在完成式，皆無法表達「到未來某時為止已完成」。

**相關文法點**:
對應「3. 未來完成式」：常搭配 by + 未來時間 或 by the time + 現在式子句。

**相似題型提醒**:
`by + 未來時間` 幾乎必然搭配 `will have + p.p.`。注意 `by` 是「到…之前」，`until` 是「持續到…」，兩者搭配的時態不同。

---

## 題目 10：現在完成式（already）的過去分詞
**答案**: B

**詳細解析**:
`has already` 之後必須接**過去分詞** ➔ **circulated**(B)。(A) circulate 是原形；(C) circulating 是現在分詞；(D) circulates 是第三人稱單數現在式。

**相關文法點**:
對應「1. 現在完成式」的完成用法：常搭配 just, already, yet。

**相似題型提醒**:
`already` 用於肯定句、`yet` 用於否定與疑問句，兩者都是現在完成式的標記詞，位置通常在 have/has 與 p.p. 之間。

---

## 題目 11：未來完成式（by the time + 現在式）
**答案**: C

**詳細解析**:
`by the time` 引導的時間子句用**現在式代替未來式**（begins），主句則用未來完成式表示屆時已完成 ➔ **will have finalized**(C)。(A) 是現在式；(B) 是過去式；(D) 是過去完成式。

**相關文法點**:
對應「3. 未來完成式」：`By the time you read this, I will have left.`

**相似題型提醒**:
同樣是 `by the time`，子句用**過去式**時主句配過去完成式，子句用**現在式**時主句配未來完成式。先看子句的時態再決定主句。

---

## 題目 12：現在完成式（經驗）的過去分詞
**答案**: B

**詳細解析**:
`has never` 之後接**過去分詞**表示至今為止的經驗 ➔ **reported**(B)。(A) 是原形；(C) 是現在分詞；(D) 是現在式。

**相關文法點**:
對應「1. 現在完成式」的經驗用法：常搭配 ever, never, before, once, times。

**相似題型提醒**:
`Since + 過去時間點` 與現在完成式是固定組合。注意 since 子句本身用**過去式**，主句才用完成式。

## 題目 13：過去完成式（過去的過去）
**答案**: C

**詳細解析**:
貨件離港**先於**海關人員完成文件這個過去動作 ➔ 先發生的用過去完成式 **had departed**(C)。(A) 是現在式；(B) 過去簡單式無法標示先後順序；(D) 是未來式。

**相關文法點**:
對應「2. 過去完成式」：`The train had left before I arrived at the station.`

**相似題型提醒**:
`before` 與 `after` 本身已標示先後，有時可以省略過去完成式而全用過去式；但選項同時提供兩者時，先發生的仍以 had + p.p. 為標準答案。

## 題目 14：現在完成式（over the past + 期間）
**答案**: C

**詳細解析**:
`Over the past three years` 表示從過去延續到現在 ➔ 用現在完成式 **has fallen**(C)。(A) 是現在式；(B) 過去簡單式會把期間講成已結束；(D) 是過去完成式。

**相關文法點**:
對應「1. 現在完成式」的多益必考關鍵字：over/in/for the past/last few years。

**相似題型提醒**:
`over the past…` 與 `in recent years` 都是現在完成式的標記。這類題只要抓住時間片語，不必分析句意就能作答。

## 題目 15：未來完成式（子句用現在式）
**答案**: C

**詳細解析**:
`By the time` 子句用現在式 `is reviewed` 代替未來式，主句表示屆時已完成 ➔ **will have published**(C)。(A) 是現在式；(B) 是過去式；(D) 是過去完成式。

**相關文法點**:
對應「3. 未來完成式」與「📝 秒殺公式」：看到 `by the time + 現在式` 秒選未來完成式。

**相似題型提醒**:
時間子句「用現在式代替未來式」是這題的隱藏考點——子句寫成 `will be reviewed` 反而是錯的。
