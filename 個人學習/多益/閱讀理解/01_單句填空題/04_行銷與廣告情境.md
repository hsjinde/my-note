# 04_行銷與廣告情境

## 📝 答題策略
行銷與廣告情境的單句填空題，常出現在廣告文案、促銷公告、品牌重塑、社群行銷成效報告中。掌握以下技巧：
1.  **先看選項判斷詞性或句構**：若四個選項是同一字根的詞性變化，先找空格在句中的角色（修飾名詞、當主詞補語、修飾動詞…），不必先讀懂全句語意。
2.  **廣告情境常見固定搭配**：be targeted at（鎖定）、roll out（推出）、air（播出廣告）等，直接背誦搭配用法，不要用中文邏輯推導。
3.  **分詞修飾廣告/商品時，判斷主動或被動**：廣告「被播出」用過去分詞，商品「被展示」也用過去分詞；執行動作的一方才用現在分詞。
4.  **看到 since + 過去時間點** ➔ 優先考慮現在完成式或完成進行式，表示動作從過去持續至今。
5.  **假設語氣句型（Had + 主詞 + p.p.）** ➔ 為與過去事實相反的假設，主要子句須用 would have + p.p.。
