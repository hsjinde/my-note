# 06_不定詞三大功能進階 - 詳細解答

## 題目 1：形容詞用法（介係詞受詞留存）
**答案**: C

**詳細解析**:
`experienced enough to advise` 是 `adj + enough to V` 句型，空格考的是 advise 是否需要接不定詞，advise 是及物動詞可直接接受詞，不需要留介係詞。此處重點是「enough to V」固定結構，空格必須是 to + 原形動詞，故選 (C)。

**相關文法點**:
對應正文「1. 形容詞用法進階」與 01_不定詞筆記中的 too...to / enough to 句型。

**相似題型提醒**:
若改成 need a mentor to rely on，則 on 不可省略，因為 rely 是介係詞動詞；但 advise 本身是及物動詞不需要介係詞，兩者判斷邏輯不同，作答前務必先確認該動詞是否為介係詞動詞。

## 題目 2：形容詞用法（to be p.p. 被動修飾）
**答案**: C

**詳細解析**:
agreements 不會自己「簽署」，而是被簽署的對象，屬於正文 1-C 提到的「名詞是尚待處理的事物」，因此不定詞須用被動式 **to be signed**，而非主動的 to sign。

**相關文法點**:
對應正文「1-C. 名詞地位是『該做的事』，不定詞須用被動語態」。

**相似題型提醒**:
凡看到 contracts / documents / issues / proposals 等「等待被處理」的名詞後面接不定詞空格，先確認語態方向，優先考慮 to be p.p.。

## 題目 3：副詞用法（表目的）
**答案**: C

**詳細解析**:
「stayed late」加上不定詞片語說明「留到很晚是為了什麼」，屬於典型的表目的用法，直接用 **to correct** 即可，不需要 in order to（此處為單純動詞片語，非正式書信開頭）。

**相關文法點**:
對應正文「2-A. 表目的」。

**相似題型提醒**:
表目的的不定詞可以直接用 to V，不一定要出現 in order to / so as to，兩者是同義但正式程度不同，考題常會兩者都出現在選項中製造混淆。

---

## 題目 4：副詞用法（否定目的 so as not to）
**答案**: A

**詳細解析**:
句意「為了不延誤董事會核准」，否定的目的句型固定寫法為 **so as not to V** 或 **in order not to V**，not 必須緊接在 to 之前。選項 (C) In order to not delay 語序錯誤（not 應放在 to 前面而非 to 後面），故不可選；(B)(D) 文法結構錯誤。

**相關文法點**:
對應正文「2-A」與補充秒殺公式第 4 條「so as not to 的位置」。

**相似題型提醒**:
否定不定詞的 not 永遠緊貼在 to 前面：not to V，而不是 to not V，這是台灣考生常見的語序錯誤。

---

## 題目 5：副詞用法（表結果 only to V）
**答案**: B

**詳細解析**:
句子前段「rushed across town to deliver」描述努力的行動，後段接逗號加不定詞表示「結果卻」，是典型的 **only to find** 句型，表達事與願違的結果。

**相關文法點**:
對應正文「2-C. 表結果」與補充秒殺公式第 5 條。

**相似題型提醒**:
only to V 前面幾乎都會出現「趕去、努力、嘗試」等動作動詞，且後面接的動詞語意通常是「發現、得知」等，一看到這個語感組合即可秒選 only to V。

## 題目 6：名詞用法（假主詞 it + of + 人，評價人的特質）
**答案**: A

**詳細解析**:
句意「主管沒有先詢問任何人就重新分配工作，相當不小心／欠考慮」，這是在評價「主管」這個人的行為特質，屬於評價人物的形容詞，須搭配 of，語意上 careless（粗心的）最符合「未經思考就做決定」的負面評價；careful、necessary、essential 語意或用法皆不合。

**相關文法點**:
對應正文「3-A」與補充秒殺公式第 8 條「假主詞 it + for/of 判斷」。

**相似題型提醒**:
evaluate 人的特質形容詞常見：kind, thoughtful, considerate, careless, rude, wise（wise 可評價事或人）；evaluate 事情本身則用 important, necessary, essential, vital 等，須先判斷形容詞語意類別再選介係詞。

## 題目 7：副詞用法（such...as to 表結果）
**答案**: A

**第一空：(A) such　第二空：(A) as to cause**

**詳細解析**:
句型為 `such + a + adj + N + as to V`，表示「如此…以致於」。第一空須填 such（不能填 so，因為 so 後面直接接形容詞不接「a+名詞」結構）；第二空須完整寫成 as to cause，不能只寫 that cause（缺少連接詞完整子句）或 as causing（結構錯誤）。

**相關文法點**:
對應正文「2-C」與補充秒殺公式第 6 條「such...as to 與 so...that 的轉換」。

**相似題型提醒**:
若名詞前面沒有更改為「a + adj + N」結構，也可以用 so + adj + as to V（不加冠詞名詞），例如題目 15 即為此變化版本，兩者不要混淆使用時機。

## 題目 8：名詞用法（假受詞 it）
**答案**: B

**詳細解析**:
`consider + it + adj + to V` 是典型假受詞句型，因為真正受詞 to document every transaction 太長，須用 it 先佔住受詞位置，再把不定詞片語移到句尾。選項 that / this / them 皆無法搭配此固定句型。

**相關文法點**:
對應正文「3-B. 當受詞：與『假受詞 it』搭配的固定句型」與補充秒殺公式第 9 條。

**相似題型提醒**:
find / make / consider / think 是最常見的四個「假受詞 it」動詞，看到「動詞 + it + 形容詞/名詞 + to V」的框架即可直接判斷考點。

---

## 題目 9：名詞用法（當主詞補語）
**答案**: C

**詳細解析**:
「our current objective」後面應該接一個說明「目標內容」的補語，語意上表達「未來要達成的目標」，符合正文「3-C. 當主詞補語」中 be + to V 描述未來目標的用法，故選 is to expand。is expanding 描述的是「正在進行的事」，語意上與「目標」不搭。

**相關文法點**:
對應正文「3-C」與補充秒殺公式第 10 條「不定詞當補語 vs. 動名詞當補語」。

**相似題型提醒**:
凡主詞是 goal, objective, priority, purpose, plan 等表達「目標／計畫」的名詞，主詞補語優先考慮 to V，而非 Ving。

## 題目 10：副詞用法（情緒形容詞 + to V 表原因）
**答案**: C

**詳細解析**:
was genuinely ______ to receive 需要一個過去分詞形容詞放在 be 動詞後面，surprised to receive 表達「因為收到...而感到驚訝」的原因用法。surprising 是主動語態形容詞（用於形容令人驚訝的事物本身），surprise 是動詞/名詞原形，to surprise 不合句構，皆不合。

**相關文法點**:
對應正文「2-B. 表原因（情緒形容詞 + to V）」與補充秒殺公式第 7 條。

**相似題型提醒**:
情緒動詞的判斷口訣：形容人的感受用過去分詞（surprised, pleased, disappointed），形容引發情緒的事物用現在分詞（surprising, pleasing, disappointing）。

---

## 題目 11：形容詞用法（介係詞動詞留存介係詞）
**答案**: B

**詳細解析**:
this program 是 work with 的邏輯受詞（work with the program），屬於正文「1-A」介係詞動詞留存介係詞的情況，因此須寫成 **to work with**，介係詞 with 不可省略。選項 (A) 缺少 to，(C) 動名詞不合此處形容詞片語的結構，(D) to be worked 語意錯誤（程式不是被工作，而是被使用/操作）。

**相關文法點**:
對應正文「1-A. 名詞是不定詞動作的邏輯受詞」。

**相似題型提醒**:
判斷方法：把不定詞還原成完整句子「work with this program」，發現 with 是必要介係詞，就知道修飾名詞時 with 要留著。

---

## 題目 12：名詞用法（假主詞 it 開頭句型）
**答案**: A

**詳細解析**:
句子後半 for the procurement office to verify... 是不定詞片語的真正主詞，前面必須用假主詞 **It** 開頭，寫成 It is standard practice for sb to V。That / There / This 皆無法在文法上與後面的 for sb to V 結構搭配成立。

**相關文法點**:
對應正文「3-A. 真主詞 vs. 假主詞 it」。

**相似題型提醒**:
It is + n./adj. + for sb + to V 是固定框架，句首只要出現 for + 人 + to V，幾乎可以確定前面要用 It 起頭。

---

## 題目 13：副詞用法（表目的，句型比較）
**答案**: C

**詳細解析**:
空格後面直接接原形動詞 reduce，能與原形動詞直接連用表目的的只有 **in order to**（in order to + 原形動詞）；for 後面通常接名詞或動名詞，so that 後面須接完整子句，so as 則不能單獨使用（須寫成 so as to）。

**相關文法點**:
對應正文「2-A. 表目的」。

**相似題型提醒**:
純粹的 so as 或 for 若後面直接接原形動詞是錯誤結構，須特別留意選項中「看似正確但少了 to」的陷阱，例如 so as reduce（錯）。

---

## 題目 14：名詞用法（假受詞 it，動詞 find 的變化）
**答案**: B

**詳細解析**:
found ______ necessary to reassign 為 find + it + adj + to V 的假受詞句型，found it necessary to reassign 表示「認為有必要重新分配」。that / so / this 都無法填入這個固定框架的受詞位置。

**相關文法點**:
對應正文「3-B」與補充秒殺公式第 9 條。

**相似題型提醒**:
除了 consider，find 也是多益常考的假受詞動詞，兩者句型完全相同：find/consider + it + adj + to V。

---

## 題目 15：副詞用法（so...as to 表結果，無冠詞版本）
**答案**: A

**第一空：(A) so　第二空：(A) as to**

**詳細解析**:
句型為 `so + adj + as to V`，此處 impressive 前面沒有冠詞加名詞（不是 a significant obstacle 這種「adj + N」結構），因此要用 so 而非 such（such 通常搭配「a/an + adj + 名詞」）。第二空固定接 as to approve，不能只寫 to（缺少 as，文法不完整，語感也偏弱）。

**相關文法點**:
對應正文「2-C. 表結果」與補充秒殺公式第 6 條。

**相似題型提醒**:
辨別 so 或 such 的關鍵在於後面有沒有名詞：so 直接加形容詞/副詞（no 名詞），such 加「a/an + adj + 名詞」或「adj + 複數／不可數名詞」，題目 7 與題目 15 正好是兩種版本的對照。
