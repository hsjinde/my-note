# 03_分詞與分詞構句 - 詳細解答

## 題目 1：單句填空 - 分詞修飾名詞（被動）
**答案**: C

**詳細解析**:
`the report` 是被財務團隊「準備」的，主詞（報告）與動作之間是被動關係，故選過去分詞。(A) prepare 為原形動詞，不能單獨修飾名詞；(B) preparing 為現在分詞，表示報告「主動準備」，語意不通；(D) to prepare 為不定詞，不符合分詞修飾名詞的用法。正確答案為 **(C) prepared**。

**相關文法點**:
對應主章節「1. 分詞作形容詞：修飾名詞」，過去分詞 (p.p.) 表示「被動、完成」的狀態。

**相似題型提醒**:
判斷分詞主動/被動時，先找出分詞與其修飾名詞的邏輯關係：名詞是動作的「發動者」用 V-ing，名詞是動作的「承受者」用 p.p.。

## 題目 2：單句填空 - 完成式分詞構句
**答案**: C

**詳細解析**:
句意為「完成簡報之後，經理回答了幾個問題」，強調分詞構句的動作（完成簡報）發生在主句動作（回答問題）**之前**，因此須用完成式分詞 having p.p.。(A) Finish 為原形動詞，不能作句首分詞構句；(B) Finished 為單純過去分詞，只能表達「被完成」的被動意涵，語意不符（她是主動完成簡報者）；(D) To finish 為不定詞，不符合分詞構句的文法。正確答案為 **(C) Having finished**。

**相關文法點**:
對應補充秒殺公式「完成式分詞 (Having p.p.)：表示分詞構句的動作發生在主句動作之前」。

**相似題型提醒**:
簡單分詞構句 (V-ing/p.p.) 表示與主句「同時發生」；完成式分詞構句 (Having p.p.) 表示「先於」主句動作發生，兩者時間關係不同，考題常以此設計陷阱。

## 題目 3：單句填空 - 獨立分詞構句 (with + O + p.p.)
**答案**: B

**詳細解析**:
`with + several complaints + ___` 中，complaints（投訴）是被顧客「提出/歸檔」的，受詞與動作之間是被動關係，故選過去分詞。(A) file 為原形動詞；(C) filing 為現在分詞，表示投訴「主動提出」，語意不通（投訴不會自己主動做動作）；(D) to file 為不定詞，不符合獨立分詞構句的文法。正確答案為 **(B) filed**。

**相關文法點**:
對應補充秒殺公式「獨立分詞構句 (with + O + 分詞)：受詞後方接的動作若受詞是被動承受，用 p.p.」。

**相似題型提醒**:
獨立分詞構句判斷方式與一般分詞修飾名詞相同：先看 with 後面的受詞是動作的主動發出者還是被動承受者。

## 題目 4：單句填空 - 分詞轉化之介系詞
**答案**: A

**詳細解析**:
`Given`（鑒於）已固定化為介系詞用法，後方直接接名詞片語（the current economic downturn），不需再判斷主動/被動關係。(B) Give 為原形動詞，不能放在句首引導此類子句；(C) Giving 為現在分詞，若使用會產生「誰在給予」的邏輯主詞問題，與句意不符；(D) To give 為不定詞，文法不通。正確答案為 **(A) Given**。

**相關文法點**:
對應主章節「4. 多益常考分詞慣用語」，Given (that) 表示「鑒於/假設」。

**相似題型提醒**:
同類固定化分詞介系詞還有 Regarding, Concerning, Considering, Judging from, Compared to/with，皆可視為固定表達直接使用，不需分析主動被動。

## 題目 5：短文填空 - 分詞修飾名詞 / 分詞慣用語
**答案**: (1) C　(2) C

**詳細解析**:
(1) `the building renovation` 是被「排定」開始的，名詞與動作之間是被動關係，故選過去分詞 **(C) scheduled**（be scheduled to V 亦為固定搭配）。
(2) `Considering the inconvenience`（考慮到這個不便）是固定分詞轉化介系詞用法，故選 **(C) Considering**。

**相關文法點**:
對應主章節「1. 分詞作形容詞：修飾名詞」與「4. 多益常考分詞慣用語」。

**相似題型提醒**:
短文閱讀中常見「分詞修飾名詞」與「分詞轉化介系詞」同時出現，需分別依各自的判斷原則作答，不可混用同一套邏輯。
