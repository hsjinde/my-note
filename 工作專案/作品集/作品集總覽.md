## 各專案摘要

### CORE PULSE

個人品牌網站本身就是作品。重點在 Edge-Native 雙運行時（React SPA 走 CDN + Pages Functions 處理動態），以及用 Playwright 把無障礙焦點環、SEO sitemap 同步、CSP 主題載入寫成 CI 契約——路由沒進 sitemap 就 build fail。16 個測試檔、80 個測試、6 支 E2E。

`/telemetry` 那頁我在簡報裡特別講清楚了：它是 Three.js GPU shader 加示波器 HUD 的**訊號分析器介面**，不是接了監控後端的儀表板。它展示的是 code-splitting（550KB 的 WebGL chunk 不進首頁）與 WebGL 資源生命週期管理。站上真的在量的可觀測性是 Footer 的 `/api/health` 心跳與 `PerformanceObserver` 量的 LCP。

### my-note-web

把這個 Obsidian Vault 接上公開網頁。核心是 Sharded KV 儲存模型（整站導覽壓成一次 KV 讀取）、Webhook 增量同步 + Tarball 全量災難復原雙管線、GitHub Contents API 樂觀鎖回寫防覆蓋，以及不養 Vector DB 的全記憶體 Bigram 兩階段計分 RAG。284 篇公開筆記、45 篇私有 wiki 硬隔離；15 個測試檔、83 個測試。

### 大阪旅券 OSAKA TRIP

Obsidian Markdown 當單一資料來源，CI 建置成靜態站；收藏與待辦狀態走 Cloudflare D1，斷線退回 localStorage、連線後補送。設計上是「御朱印帳」意象的完整設計系統，朱印紅填色面積硬性限制 ≤10%。Zod 在建置期擋掉格式錯誤的 Frontmatter。36 個測試檔、188 個測試。

### Osaka Vault

知識庫本身的工程化：原始剪藏層唯讀、AI 只寫 wiki 層，避免 LLM 污染 grounding 來源；圖片全部搬到 Cloudflare R2 並強制 ASCII key（解掉 Worker URL 解碼 404）；用 `wiki/log.md` 的 timestamp + 7 天 TTL 做增量消化，省掉重複燒 token。行程草稿以已付款訂單為最高真值，未確認項目一律標「待定 📌」。161 個 wiki 頁、148 筆實體頁。

### Postfix Manager

自架郵件伺服器的管理層。三個可談的硬點：用 Nginx `ngx_stream_module` 做四層 SSL Stream 繞過主機商封鎖的郵件埠；Django 介面自動化多網域 TLS + OpenDKIM 金鑰 + DNS 記錄編排；以及查出 Fail2ban 規則掛在 `INPUT` 鏈卻被 Docker DNAT 繞過、改掛 `DOCKER-USER` 鏈才生效。**本篇已脫敏**，實際埠映射、主機商與封鎖網段面試時再補。

## 誠實聲明

這幾份簡報裡沒有的東西，我也講清楚，免得面試時對不上：

- **沒碰過 Kubernetes**。容器編排的經驗都是 Docker Compose 等級，單機多容器，不是叢集。
- **沒碰過 Prometheus / Grafana**。這幾個專案的「可觀測性」是 health check、LCP 量測、CI 測試防護網，不是指標蒐集與告警系統。
- **沒有正式 on-call 經驗**。自架服務出事是我自己修，但那跟輪班待命、有 SLO 與事故報告的責任結構不一樣。

這三項是我下一階段想補的，也是想往 SRE 走的原因。與其在履歷上模糊帶過，不如寫在這裡。
