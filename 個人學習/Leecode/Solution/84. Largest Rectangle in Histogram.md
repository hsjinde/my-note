## 題目描述 (中文摘要)
給定一個非負整數陣列 `heights`，代表柱狀圖中每根柱子的高度，每根柱子的寬度都是 1。請找出柱狀圖中能勾勒出的**最大矩形面積**。矩形必須由相鄰的柱子組成，高度不能超過範圍內最矮的那根柱子。

限制：`1 <= heights.length <= 10^5`，`0 <= heights[i] <= 10^4`。

範例：
```
輸入：heights = [2,1,5,6,2,3]
輸出：10
說明：高度 5 與 6 的兩根柱子，取高度 5、寬度 2，面積 10

輸入：heights = [2,4]
輸出：4
```

```
        ▇
      ▇ ▇
      ▇ ▇
      ▇ ▇   ▇
  ▇   ▇ ▇ ▇ ▇
  ▇ ▇ ▇ ▇ ▇ ▇
  2 1 5 6 2 3
```

## 思路總覽 (Overview & Interview Plan)

### 中文解題計畫
任何一個最大矩形，高度一定等於範圍內某根柱子的高度。所以換個問法：**以每根柱子當作矩形的高，它最多能往左右延伸多寬？** 答案就是「左邊第一根比它矮的柱子」與「右邊第一根比它矮的柱子」之間的距離。
1. **演算法選擇**：採用 **單調遞增堆疊 (Monotonic Increasing Stack) + 哨兵 (Sentinel)**，一次掃描同時找出每根柱子的左右邊界。
2. **具體步驟**：
   - 堆疊存 index，對應的高度由底到頂嚴格遞增。
   - 掃到第 `i` 根柱子時，只要堆疊頂端的柱子 `>=` 目前高度，就把它彈出：`i` 是它的右邊界，彈出後的新頂端是它的左邊界，寬度為 `i - left - 1`。
   - 在陣列尾端補一根高度 0 的哨兵柱，保證掃描結束時堆疊內所有柱子都會被彈出結算。
   - 每次彈出都更新最大面積。

### English Interview Plan
Find the largest rectangle that fits under the histogram, where every bar has width 1.
1. **Strategy**: The optimal rectangle's height equals some bar's height, so for each bar we need the nearest shorter bar on both sides. A monotonic increasing stack finds both boundaries in one pass, giving $O(N)$ time instead of the $O(N^2)$ brute force.
2. **Execution**:
   - **Initialization**: An empty stack of indices and `max_area = 0`; append a sentinel bar of height 0 to the iteration so every bar gets popped at the end.
   - **Iterative Step**: For each index `i`, while the bar on top of the stack is at least `heights[i]`, pop it. Its right boundary is `i`, its left boundary is the new stack top (or `-1` if empty), so `width = i - left - 1`. Then push `i`.
   - **Key Insight**: When a bar is popped, the bar beneath it on the stack is the nearest shorter bar on the left, and the current bar is the first one on the right that is not taller. Each index is pushed and popped exactly once.

## 演算法詳解

暴力解是枚舉所有左右端點 `(l, r)`，邊掃邊維護區間最小值，面積為 `min * (r - l + 1)`，需要 $O(N^2)$。在 $N = 10^5$ 時大約 $5 \times 10^9$ 次運算，一定超時。

換成「以柱子為中心」的視角：對每根柱子 `j`，若知道
- `left`：`j` 左邊**第一根比它矮**的柱子 index（沒有則為 `-1`）
- `right`：`j` 右邊**第一根不比它高**的柱子 index（沒有則為 `n`）

那以 `heights[j]` 為高的最寬矩形就是 `heights[j] * (right - left - 1)`。

「找左右第一個較小值」正是單調堆疊的拿手題。維持一個高度嚴格遞增的堆疊：
- 新柱子比頂端高 → 直接推入，頂端那根的右邊界還沒出現。
- 新柱子不比頂端高 → 頂端那根的右邊界就是現在這根，可以結算；而它在堆疊中的下一個元素，因為堆疊遞增，必然比它矮，而且兩者之間的柱子都已在先前被彈出（都比它高或一樣高），所以下一個元素就是它的左邊界。

尾端的哨兵 0 不比任何柱子高（高度皆 `>= 0`），會把殘留在堆疊中的柱子全部逼出來結算，省掉迴圈結束後另外處理的程式碼。

### 狀態變化 (State Transitions)
以 `heights = [2,1,5,6,2,3]` 為例，掃描序列為 `[2,1,5,6,2,3,0]`（最後的 0 是哨兵）。堆疊欄位寫成 `index(高度)`：

| i | h | 彈出的柱子 | left | 寬度 `i - left - 1` | 面積 | max | 推入後堆疊 |
|---|---|---|---|---|---|---|---|
| 0 | 2 | — | — | — | — | 0 | `[0(2)]` |
| 1 | 1 | 0(2) | -1 | 1 | 2 | 2 | `[1(1)]` |
| 2 | 5 | — | — | — | — | 2 | `[1(1), 2(5)]` |
| 3 | 6 | — | — | — | — | 2 | `[1(1), 2(5), 3(6)]` |
| 4 | 2 | 3(6) | 2 | 1 | 6 | 6 | |
|   |   | 2(5) | 1 | 2 | **10** | 10 | `[1(1), 4(2)]` |
| 5 | 3 | — | — | — | — | 10 | `[1(1), 4(2), 5(3)]` |
| 6 | 0 | 5(3) | 4 | 1 | 3 | 10 | |
|   |   | 4(2) | 1 | 4 | 8 | 10 | |
|   |   | 1(1) | -1 | 6 | 6 | 10 | `[6(0)]` |

最終答案 10。注意 `i = 4` 時彈出 `2(5)`：它的右邊界是 `i = 4`，左邊界是彈出後的新頂端 `1`，所以寬度是 `4 - 1 - 1 = 2`（涵蓋 index 2、3），而不是 `4 - 2 = 2` 這種剛好巧合的算法——後者在其他輸入會出錯，見常見誤區。

## 程式碼實作

```python
class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:
        max_area = 0
        # 存 index，對應高度由底到頂嚴格遞增
        stack = []

        # 尾端補高度 0 的哨兵：不比任何柱子高，掃到它時會把堆疊全部清空結算
        # 用 heights + [0] 產生新串列，不改動呼叫端傳進來的陣列
        for i, h in enumerate(heights + [0]):
            # 頂端柱子的右邊界出現了：i 是右邊第一根不比它高的柱子
            while stack and heights[stack[-1]] >= h:
                height = heights[stack.pop()]
                # 彈出後的新頂端是左邊第一根比它矮的柱子；堆疊空了代表左邊沒有更矮的
                left = stack[-1] if stack else -1
                max_area = max(max_area, height * (i - left - 1))
            stack.append(i)

        return max_area
```

## 正確性說明

1. **不重複 (No Redundancy)**：每個 index（含哨兵）只被推入一次，最多被彈出一次；每次彈出只結算一個矩形。被彈出的柱子不會再回到堆疊，因此不會被重複結算。
2. **不遺漏 (Completeness)**：
   - **算出來的矩形都合法**：柱子 `j` 被彈出時，`(left, j)` 之間的柱子都已被彈出，且是被 `j` 或一連串最終被 `j` 彈出的柱子擠掉的，高度都 `>= heights[j]`；`(j, i)` 之間的柱子曾疊在 `j` 上方，高度都 `> heights[j]`。所以以 `heights[j]` 為高、寬 `i - left - 1` 的矩形確實放得進去。
   - **最佳解一定會被算到**：設最佳矩形範圍為 `[L, R]`、高度為 `H`。取範圍內高度等於 `H` 且**最靠右**的柱子 `j`。因為矩形無法再擴張，`heights[L-1] < H`、`heights[R+1] < H`（或已到陣列邊界）；又因 `j` 是最靠右的最矮柱，`(j, R]` 的柱子都嚴格大於 `H`。因此 `j` 會在 `i = R + 1` 時被彈出，彈出後的新頂端正是 `L - 1`，算出的寬度恰好是 `R - L + 1`。
   - 哨兵保證每根真實柱子最終都會被彈出，不會有柱子漏掉結算。
3. **邊界條件**：
   - 單一柱子 `[5]`：哨兵彈出它，`left = -1`，寬度 1，答案 5。
   - 含高度 0 的柱子 `[0,0]`：每次彈出面積都是 0，答案 0；高度 0 的柱子同時也像一道牆，把左右兩邊切開。
   - 全部遞增 `[1,2,3,4,5]`：前面都只推入不彈出，最後由哨兵一次清空，答案 `3 * 3 = 9`。
   - 全部相同 `[2,2,2]`：因為用 `>=`，每根都會把前一根彈出（前一根寬度被低估），但最後一根由哨兵彈出時 `left = -1`，寬度 3，答案 6。

## 複雜度分析

- **Time Complexity**: $O(N)$
  - 其中 $N$ 為柱子數量（`heights` 的長度）。雖然有巢狀的 `while`，但每個 index 只推入一次、最多彈出一次，攤銷 (Amortized) 後總操作數是 $O(N)$。不論輸入形狀，最好與最壞情況都是 $O(N)$。
- **Space Complexity**: $O(N)$
  - `heights + [0]` 會複製一份 $O(N)$ 的串列。
  - 堆疊大小：最好情況是嚴格遞減的輸入（如 `[5,4,3,2,1]`），每根新柱子都把前一根彈出，堆疊始終只有 1 個元素；最壞情況是遞增輸入（如 `[1,2,3,4,5]`），所有柱子都堆在堆疊裡直到哨兵出現，$O(N)$。

## 常見誤區

1. **忘記處理掃描結束後殘留在堆疊的柱子**：沒有哨兵也沒有收尾迴圈時，遞增輸入 `[1,2,3,4,5]` 從頭到尾都不會觸發彈出，會回傳 0，正確答案是 9。補哨兵 0 或在迴圈後以 `right = n` 結算剩餘柱子，二擇一。
2. **寬度寫成 `i - 彈出的 index`**：這只算到被彈出柱子本身往右的範圍，漏掉了它往左能延伸的部分。`[2,1,2]` 在哨兵階段彈出高度 1 的柱子（index 1）時，錯誤寫法得到寬度 `3 - 1 = 2`、面積 2；正確寬度是 `3 - (-1) - 1 = 3`、面積 3。範例 `[2,1,5,6,2,3]` 剛好不會出錯，所以只跑範例測不出來。
3. **堆疊空了時的左邊界處理錯**：彈出後堆疊為空，代表左邊沒有比它矮的柱子，左邊界要當作 `-1`（寬度 `i`）。直接寫 `stack[-1]` 會 `IndexError`；寫成 `left = 0` 則寬度少 1，`[2,1,2]` 中高度 1 那根會被算成寬度 2。
4. **用 `heights.append(0)` 直接改輸入**：在 LeetCode 上能過，但呼叫端的陣列被偷偷多了一個元素；若同一個陣列被重複呼叫兩次，第二次會再多一個 0。面試時用 `heights + [0]` 或在迴圈後 `pop()` 還原比較安全。
5. **以為 `>` 和 `>=` 只有一個是對的**：兩者都正確。用 `>=` 時相同高度的前一根會被提早彈出、寬度被低估，但同高的最後一根會算到完整寬度；用 `>` 時相同高度會疊在堆疊裡，要等更矮的柱子出現才一起結算，最底下那根會拿到完整寬度。重點是想清楚自己的寫法中，「誰」負責算到完整寬度。

## 延伸思考

### NeetCode 寫法：堆疊存 `(起點, 高度)`
另一種常見寫法是讓堆疊記錄「這個高度可以往左延伸到哪裡」。彈出較高的柱子時，新柱子繼承被彈出柱子的起點，因為那些位置都比新柱子高，新柱子也能往左延伸過去：

```python
class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:
        max_area = 0
        stack = []  # (start, height)

        for i, h in enumerate(heights):
            start = i
            while stack and stack[-1][1] > h:
                index, height = stack.pop()
                max_area = max(max_area, height * (i - index))
                start = index
            stack.append((start, h))

        for index, height in stack:
            max_area = max(max_area, height * (len(heights) - index))
        return max_area
```

這個版本的寬度直接寫 `i - index` 是對的，因為 `index` 已經是**延伸後的起點**，不是柱子本身的位置——這也是誤區 2 容易混淆的原因：同樣的式子，堆疊存的東西不同，意義就不同。

### 兩次掃描：先求左右邊界陣列
也可以分開做：一次由左往右用單調堆疊求 `left[i]`，一次由右往左求 `right[i]`，最後再掃一次算 `heights[i] * (right[i] - left[i] - 1)`。時間同樣 $O(N)$，多用兩個陣列，但每一步的意義更直觀，適合第一次接觸這題時先寫出來再優化成一次掃描。

### 分治法 (Divide and Conquer)
以區間最矮柱子為界切成左右兩半，答案是「最矮柱 × 整段寬度」、左半最佳、右半最佳三者取最大。平均 $O(N \log N)$，但輸入已排序時會退化成 $O(N^2)$；搭配線段樹 (Segment Tree) 查區間最小值可穩定在 $O(N \log N)$。面試中通常只需要提到它的存在，單調堆疊才是預期解。

## 小結

這題是單調堆疊「找左右第一個較小值」的代表題：把「找最大矩形」轉換成「每根柱子當高時能延伸多寬」，就能在一次掃描內解決。

**核心觀念：**
- 最大矩形的高度必定等於某根柱子的高度，所以只要對每根柱子求左右第一個較矮的邊界。
- 柱子被彈出的那一刻，左右邊界同時確定：右邊界是目前 index，左邊界是彈出後的新頂端，寬度是 `i - left - 1`。
- 尾端補哨兵 0 可以把收尾邏輯併進主迴圈，避免漏算殘留在堆疊的柱子。
