# 04_假設語氣 詳解

## 題目 1：與過去事實相反（If 子句過去完成式）
**答案**: B

**詳細解析**:
主要子句 "it would have avoided the product recall" 使用 `would have + p.p.`，代表這是「與過去事實相反」的假設語氣，If 子句應搭配**過去完成式** (had + p.p.)。(A) conducts 是現在式，(C) conducted 是過去式，(D) has conducted 是現在完成式，皆不符合過去事實相反的公式。故選 (B) had conducted。

**相關文法點**:
對應主章節「2. 與過去事實相反 (Past Unreal)」公式：`If + S + had + p.p., S + would/could/should/might + have + p.p.`

**相似題型提醒**:
先看主要子句（逗號後）的動詞形態，反推 If 子句應該用哪一種假設時態，是最快的解題捷徑。

## 題目 2：Should 開頭的倒裝句（與未來相反）
**答案**: A

**詳細解析**:
句首沒有 If，且句子結構是「助動詞 + 主詞 + 原形動詞」的倒裝形式，加上後面主要子句是祈使句 "please do not hesitate to contact"，符合「與未來相反/萬一」假設語氣的倒裝句型。(B) Would、(C) Were、(D) Had 均不符合此倒裝句型的語意與結構（Were 用於與現在事實相反的倒裝，Had 用於與過去事實相反的倒裝）。故選 (A) Should。

**相關文法點**:
對應主章節「考點 1：條件句的倒裝 (If 省略)」第 2 點「與未來相反倒裝 (最常考)：Should + S + V, 祈使句」。

**相似題型提醒**:
看到句首是 Should/Were/Had 且沒有 If，且句子呈現倒裝語序，優先判斷是哪一種倒裝假設句型，再對照後半句的動詞形式確認。

## 題目 3：I wish + 過去完成式（與過去事實相反）
**答案**: C

**詳細解析**:
句意是「我希望我在訂機票之前就已經知道班表變動」，這件事發生在過去（訂機票之前），且與過去事實相反（當時並不知道），wish 後面的子句應使用**過去完成式**。(A) know 是現在式，(B) knew 是過去式（用於 wish + 與現在事實相反），(D) have known 是現在完成式，均不符合。故選 (C) had known。

**相關文法點**:
對應補充秒殺公式第 2 點「I wish + 假設語氣」：與過去事實相反時，wish 後接過去完成式。

**相似題型提醒**:
wish 後面的假設語氣時態退一格的規則和 If 子句相同：與現在相反用過去式，與過去相反用過去完成式，需依句子的時間點判斷，不能只看 wish 本身的時態。

## 題目 4：短文填空 — 條件句現在式 vs. 過去完成式倒裝
**答案**:
(1) A
(2) B

**詳細解析**:
(1) 句意是「如果合併案在下個月獲得批准，兩家公司將立即開始整合系統」，主要子句使用未來式 "will begin"，代表這是「真實條件句」（可能發生的未來事件），If 子句依規則使用**現在式**代替未來式。(B) were 用於與現在事實相反的假設語氣，(C) had been 用於與過去事實相反，(D) will be 在真實條件句的 if 子句中不可用未來式。故選 (A) is。
(2) 句意是「分析師表示，萬一交易告吹，股東將會損失可觀的價值」，句首無 If，且呈現倒裝語序（助動詞/had + 主詞 + 過去分詞），對應「與過去事實相反」的倒裝句型 Had + S + p.p.。(A) if 若使用則不構成倒裝句，且句子會缺少倒裝應有的助動詞前移；(C) unless 語意「除非」不符；(D) once 語意「一旦」不符此假設語境。故選 (B) had。

**相關文法點**:
對應主章節「3. 與未來事實相反」的真實條件句時態規則，以及「考點 1：條件句的倒裝」第 1 點「與過去相反倒裝：Had + S + p.p., S + would have p.p.」。

**相似題型提醒**:
短文中常同時出現「真實條件句（現在式代未來式）」與「假設語氣倒裝句」兩種考點，須分別判斷每個空格所屬的句型，不要互相套用公式。

## 題目 5：Without（要不是因為...與過去事實相反）
**答案**: A

**詳細解析**:
句意是「要不是技術支援團隊，伺服器當機的時間會拖得更久」，主要子句使用 `would have lasted`，屬於與過去事實相反的假設語氣，句首可用 Without 或 But for 表示「要不是因為」。(B) Unless 意思是「除非」，且不能直接接名詞構成此句型；(C) If 若使用需改寫成完整子句 (If it had not been for...)，不能直接接名詞；(D) Despite 語意「儘管」，與「要不是」的邏輯不符。故選 (A) Without。

**相關文法點**:
對應主章節「考點 2：Without / But for (要不是因為...)」— 與過去相反：`Without / But for + N, S + would have + p.p.`

**相似題型提醒**:
Without/But for 可與 Had it not been for 互換使用（見補充秒殺公式），三者皆表達「要不是因為」，但 Had it not been for 是完整倒裝子句，Without/But for 後面直接接名詞，注意句型結構差異。
