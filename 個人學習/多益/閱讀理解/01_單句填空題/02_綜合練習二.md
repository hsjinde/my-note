# 02_綜合練習二

## 📝 答題策略 🌟
1.  **空格前有冠詞 (a/an/the) 或所有格** ➔ 空格後大多接**名詞**，優先刪去動詞、副詞選項。
2.  **空格是動詞** ➔ 先確認主詞單複數（主詞動詞一致性），再確認時態線索字（yesterday, currently, since...）。
3.  **句中出現 if / unless / provided that** ➔ 判斷是假設語氣，留意主要子句與 if 子句的時態搭配。
4.  **選項出現 V-ing 與 p.p. 分詞** ➔ 判斷被修飾的名詞是「主動執行」還是「被動承受」該動作。
5.  **空格後面接完整子句** ➔ 通常選連接詞（that, because, although）；**空格後面接名詞/動名詞** ➔ 通常選介系詞（because of, despite）。
