# 03_意志動詞與建議動詞 - 詳細解答

## 題目 1：建議動詞 recommend + that 子句 + 原形動詞
**答案**: C

**詳細解析**:
recommended 為建議動詞，後方接 that 子句，子句動詞須用**原形動詞**（可視為省略 should），答案為 (C) be。(A) is 為現在式，未使用原形動詞；(B) was 為過去式；(D) being 為動名詞/現在分詞形式，皆不符合建議動詞 + that 子句的固定句型。

**相關文法點**:
對應主章節「2. 句型結構」：`S + 意志/建議動詞 + that + S + (should) + 原形動詞`。

**相似題型提醒**:
be 動詞的原形一律是 **be**，無論主詞單複數皆同，是此文法點最容易考的細節之一。

## 題目 2：意志動詞 require + that 子句 + 原形動詞
**答案**: B

**詳細解析**:
require 為意志動詞，後方 that 子句省略了 that（require that every visitor (should) wear...，此處 that 已包含在句子結構中），子句動詞須用**原形動詞**，不受第三人稱單數 every visitor 影響，答案為 (B) wear。(A) wears 是加了 -s 的第三人稱單數現在式，是常見陷阱選項；(C) wearing 為現在分詞；(D) to wear 為不定詞，皆不符合公式。

**相關文法點**:
對應主章節「2. 句型結構」表格中 require 範例：「The policy requires that all employees **wear** ID badges. (不是 wears)」。

**相似題型提醒**:
這是全題型中最常見的陷阱：主詞是第三人稱單數（every visitor, he, she），但因為前面出現 require/insist/demand 等觸發詞，子句動詞仍要用原形，不可加 -s。

## 題目 3：形容詞 essential + that 子句 + 原形動詞
**答案**: C

**詳細解析**:
It is essential that... 為「形容詞 + that 子句」句型，子句動詞須用**原形動詞**，答案為 (C) review。(A) reviews 為第三人稱單數現在式；(B) reviewed 為過去式；(D) to review 為不定詞，皆不符合此固定句型。

**相關文法點**:
對應主章節「4. 形容詞形式 (It is + adj. + that ...)」。

**相似題型提醒**:
除了 essential，同類形容詞如 important, necessary, vital, crucial, advisable, imperative, urgent 皆適用相同規則，看到 `It is + 這些形容詞 + that` 就直接秒選原形動詞。

## 題目 4：意志/建議動詞混合句型（Part 6 短文）
**答案**: (1) B　(2) C

**詳細解析**:
(1) insists that each department ___ a detailed expense report，insist 為意志動詞，之後 that 子句動詞須用**原形動詞**，答案為 (B) submit。(A) submits 為第三人稱單數現在式是常見陷阱；(C) submitted 為過去式；(D) submitting 為現在分詞，皆不符合公式。
(2) it is advisable that managers ___ any unusual expenditures，advisable 為觸發原形動詞的形容詞，之後 that 子句動詞須用**原形動詞**，答案為 (C) discuss。(A) discusses 為第三人稱單數現在式；(B) discussed 為過去式；(D) to discuss 為不定詞，皆不符合「It is advisable that + S + 原形動詞」的句型。

**相關文法點**:
對應主章節「2. 句型結構」與「4. 形容詞形式 (It is + adj. + that ...)」。

**相似題型提醒**:
同一篇短文中可能同時出現「意志動詞觸發的 that 子句」與「形容詞觸發的 that 子句」，兩者規則相同（皆用原形動詞），但觸發詞的詞性不同（動詞 vs. 形容詞），閱讀時需辨識觸發詞本身，而非死記單一句型。

## 題目 5：意志動詞 demand + that 子句 + 原形動詞（be 動詞）
**答案**: C

**詳細解析**:
demanded 為意志動詞，之後 that 子句的動詞為 be 動詞，須用原形 **be**，答案為 (C)。(A) is 為現在式；(B) was 為過去式；(D) has been 為現在完成式，皆不符合意志動詞 + that 子句的固定句型，也不是原形動詞。

**相關文法點**:
對應主章節「2. 句型結構」表格中 demand 範例，以及 insist/request 範例中 be 動詞用法（"be，不是 is"）。

**相似題型提醒**:
凡是意志/建議動詞 + that 子句，且子句主詞後面接的是 be 動詞時，答案幾乎必為 **be**，這是最容易辨識、也最常考的固定考點。
