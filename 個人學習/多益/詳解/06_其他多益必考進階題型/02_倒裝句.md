## 題目 1：單句填空 - 否定副詞倒裝
**答案**: B

**詳細解析**:
句首 "Rarely" 是否定/限制副詞，依規則後面必須倒裝，即「助動詞 + 主詞 + 動詞」。此句的時態是現在完成式的經驗描述，正確倒裝為 "have we seen"。(A) we have seen 是一般直述語序，未倒裝，違反 Rarely 開頭的倒裝規則；(C) we saw 同樣未倒裝且時態改變語意；(D) did we seeing 動詞形式錯誤（did 後面須接原形動詞 see，不可用 seeing）。

**相關文法點**:
對應主章節「1. 否定副詞倒裝」表格中的 Rarely/Seldom 用法，公式為 `否定副詞 + 助動詞/be + 主詞 + 動詞`。

**相似題型提醒**:
凡看到 Never, Rarely, Seldom, Hardly 等否定/限制副詞開頭，先確認後面是否已經倒裝，若選項有「未倒裝」的版本，通常就是陷阱選項。

## 題目 2：單句填空 - No sooner...than 倒裝
**答案**: A

**詳細解析**:
"No sooner...than" 是「一...就...」的倒裝句型，No sooner 開頭時，後面的助動詞須移到主詞前，形成 "No sooner had he received..."。(B) He had no sooner 未倒裝，是錯誤語序；(C) No sooner he had 順序顛倒，had 應該在主詞前面而非後面；(D) Had he no sooner 把 No sooner 誤放在 he 之後，破壞了固定句型結構。

**相關文法點**:
對應主章節「🔤 相關單字和片語」中補充的 `no sooner...than` 片語，屬於否定副詞倒裝的延伸用法，邏輯與 Never/Rarely 倒裝一致。

**相似題型提醒**:
`No sooner + had + S + p.p. + than + S + 過去式動詞` 是固定句型，常與 `Hardly...when` 互相考、混淆，兩者結構相同但連接詞不同（no sooner 配 than，hardly 配 when）。

## 題目 3：單句填空 - Should 倒裝假設語氣
**答案**: B

**詳細解析**:
"Should any issues arise" 是條件句 "If any issues should arise" 省略 If 之後的倒裝形式，主句應搭配祈使句或未來式，此處為祈使句，動詞須用**原形**。(A) contacting 是動名詞，不可作祈使句動詞；(C) to contact 是不定詞，同樣不符合祈使句需要原形動詞開頭的規則；(D) contacted 是過去式，不符合祈使句語態。

**相關文法點**:
對應主章節「2. 條件句倒裝 (If 省略)」表格中的 `If should V (未來)` ➔ `Should + S + V, ...`，這是多益最常考的假設語氣倒裝之一。

**相似題型提醒**:
`Should + S + 原形動詞` 開頭時，主句常見兩種形式：祈使句（原形動詞開頭）或含 will/may/should 的完整句子，兩者都要留意主句動詞形式是否正確。

## 題目 4：單句填空 - Neither 附和倒裝
**答案**: A

**詳細解析**:
A 說 "haven't finished"（否定句，用 haven't），B 想表達「我也還沒」，須用 Neither + 助動詞 + 主詞 的附和倒裝句型，助動詞須對應 A 句的 have，故為 "Neither have I"。(B) So have I 用於**肯定**附和（我也是），與 A 的否定句意不符；(C) Neither I have 語序錯誤，Neither 開頭必須倒裝（助動詞在主詞前）；(D) So I haven't 同樣未倒裝且 So 用於肯定附和，語意矛盾。

**相關文法點**:
對應主章節「4. So/Neither/Nor 的附和倒裝」，Neither + 助動詞 + 主詞 表示「...也不」的否定附和。

**相似題型提醒**:
判斷 So 或 Neither 時，先看前一句是肯定還是否定：肯定句用 So 附和，否定句用 Neither/Nor 附和，且附和的助動詞須與前一句的動詞時態一致。

## 題目 5：短文填空 - Not until 與 Only after 倒裝
**答案**: (1) A, (2) B

**詳細解析**:
第 (1) 格：句首為 "Not until the final inspection was complete"，屬於否定副詞片語開頭，後面主句必須倒裝，過去式的 be 動詞倒裝為 "was the factory allowed"，故選 was。(B) is 時態與前面 was complete 的過去式不一致；(C) the factory was 未倒裝（多了主詞在助動詞前面），不符合倒裝規則；(D) had 詞性錯誤，此處需要 be 動詞而非助動詞 had。
第 (2) 格：句首為 "Only after every safety measure had been verified"，Only + 副詞片語開頭，主要子句須倒裝，且原句是過去式一般動詞 (sign)，倒裝助動詞用 did。故選 did。(A) does 時態錯誤（應為過去式）；(C) do 時態與人稱皆不符；(D) done 不是助動詞形式。

**相關文法點**:
對應主章節「1. 否定副詞倒裝」的 Not until 用法，以及「3. Only + 副詞片語 開頭的倒裝」規則，兩者都要求後面主要子句倒裝。

**相似題型提醒**:
Not until 與 Only + 副詞片語都是常考的倒裝觸發詞，考生常忽略「be 動詞」和「一般動詞」倒裝時所需的不同助動詞形式（be 動詞本身倒裝 vs 一般動詞用 do/does/did 倒裝），需特別留意原句的動詞種類。

## 題目 6：否定副詞 never 開頭的倒裝
**答案**: A

**詳細解析**:
`Never before` 是否定副詞置於句首，主詞與助動詞要**倒裝** ➔ 助動詞提前為 **has**(A)，後接主詞 `the company` 與過去分詞。(B) 與 (D) 沒有倒裝；(C) 的助動詞時態與 `recorded` 不搭。

**相關文法點**:
對應「1. 否定副詞倒裝」：Never, Rarely, Seldom, Not only 等置於句首時要倒裝。

**相似題型提醒**:
倒裝只調動**助動詞**，主要動詞留在主詞後面。沒有助動詞時要借 do/does/did。

## 題目 7：Not only 開頭的倒裝
**答案**: A

**詳細解析**:
`Not only` 置於句首要倒裝，且後半句用 `but it also` 呼應 ➔ 借助動詞 **does**(A) 提到主詞前。(B) 沒有倒裝；(C) 與 (D) 不是助動詞形式。

**相關文法點**:
對應「1. 否定副詞倒裝」：`Not only … but also …` 的前半要倒裝。

**相似題型提醒**:
只有 `Not only` 所在的那一半倒裝，`but also` 那一半維持正常語序。這是最常被搞混的細節。

---

## 題目 8：Only + 副詞子句開頭的倒裝
**答案**: B

**詳細解析**:
`Only after…` 置於句首時主句要倒裝：助動詞在主詞前、主要動詞用原形 ➔ **did the team notice**(B)。(A) 與 (C) 沒有倒裝；(D) 的語序不是英文倒裝的形式。

**相關文法點**:
對應「3. Only + 副詞片語 開頭的倒裝」：`Only after the meeting did she realize the issue.`

**相似題型提醒**:
倒裝的是**主句**不是 Only 引導的那個子句。子句本身維持正常語序，這是判斷的關鍵。

## 題目 9：So 附和倒裝（肯定）
**答案**: A

**詳細解析**:
前句是過去式一般動詞 `exceeded`，肯定附和用 `So + 助動詞 + 主詞` ➔ **so did**(A)。(B) 的 be 動詞與前句動詞型態不合；(C) 語序顛倒；(D) 不是標準附和結構。

**相關文法點**:
對應「4. So/Neither/Nor 的附和倒裝」：`So + 助動詞 + 主詞` 表示「…也是如此」。

**相似題型提醒**:
附和句的助動詞要跟著前句：be 動詞用 so was／so is，一般動詞用 so did／so does，完成式用 so has。

---

## 題目 10：Nor 附和倒裝（否定）
**答案**: B

**詳細解析**:
前句是否定，後半也要表達否定並使用倒裝語序 `did it` ➔ 用 **nor**(B)。(A) either 不引導倒裝；(C) so 用於肯定附和；(D) and 後面不會出現倒裝語序。

**相關文法點**:
對應「4. So/Neither/Nor 的附和倒裝」：`Neither/Nor + 助動詞 + 主詞` 表示「…也不」。

**相似題型提醒**:
`nor` 本身已含否定，後面的子句不再加 not。看到 `nor did / nor was` 就是這個結構。

## 題目 11：否定介系詞片語開頭的倒裝
**答案**: A

**詳細解析**:
`Under no circumstances` 是含否定意味的片語置於句首 ➔ 助動詞要提到主詞前 **may**(A)，後接主詞 `personnel files` 與原形動詞 be。(B) 多了主詞；(C) 沒有倒裝；(D) 不是合法形式。

**相關文法點**:
對應「1. 否定副詞倒裝」：否定副詞或含否定意味的片語置於句首時倒裝。

**相似題型提醒**:
同型片語還有 `At no time`, `On no account`, `In no way`, `Not until…`。它們都會觸發主句倒裝。

## 題目 12：Only by 開頭的倒裝
**答案**: B

**詳細解析**:
`Only by + 動名詞` 置於句首時主句要倒裝，助動詞提到主詞前 ➔ **could the plant**(B)。(A) 與 (C) 沒有倒裝；(D) 出現兩個助動詞。

**相關文法點**:
對應「3. Only + 副詞片語 開頭的倒裝」：`Only by working together can we achieve this goal.`

**相似題型提醒**:
`Only by / Only after / Only when / Only then` 開頭都要倒裝。`Only` 修飾的若是主詞則不倒裝，要看清楚它修飾什麼。

## 題目 13：No sooner... than 句型
**答案**: B

**詳細解析**:
`No sooner … than …`（一…就…）是固定搭配 ➔ **than**(B)。(A) when 搭配的是 `Hardly/Scarcely … when`；(C) then 是副詞；(D) that 不用於這個結構。

**相關文法點**:
對應「1. 否定副詞倒裝」：No sooner 置於句首時前半倒裝，後半用 than 連接。

**相似題型提醒**:
兩組要分清楚：`No sooner … than` 與 `Hardly/Scarcely … when`。搭配詞用錯是這題最常見的失分點。

---

## 題目 14：條件句倒裝（省略 if）
**答案**: A

**詳細解析**:
這是 `If you should require…` 省略 if 後的**倒裝**，把 should 提到主詞前 ➔ **Should**(A)。(B) Would 與 (C) Will 不用於這個倒裝結構；(D) Did 的時態與主句的 can 不合。

**相關文法點**:
對應「2. 條件句倒裝 (If 省略)」：`Should + 主詞 + V` 是多益商務書信最常見的形式。

**相似題型提醒**:
三種條件倒裝要一起記：`Should + S + V`（未來）、`Had + S + p.p.`（過去）、`Were + S`（現在）。

## 題目 15：倒裝後主要動詞用原形
**答案**: B

**詳細解析**:
句首 `Not until…` 觸發倒裝，助動詞 `did` 已經承擔時態 ➔ 主要動詞要用**原形** **discover**(B)。(A) 是過去式；(C) 是現在分詞；(D) 是第三人稱單數現在式。

**相關文法點**:
對應「1. 否定副詞倒裝」：倒裝時助動詞在主詞前，主要動詞回到原形。

**相似題型提醒**:
看到 `did / does / do + 主詞 + ___`，空格一律是原形動詞。時態已經由助動詞表達，動詞不再變化。
