# 02_完成式 - 詳細解答

## 題目 1：現在完成式（經驗 + since 過去時間點）
**答案**: C

**詳細解析**:
"since it was founded in 1998" 表示「從 1998 年成立以來」，公司在這段期間內換過三次商標，屬於「從過去到現在的經驗」，應使用**現在完成式**。故選 (C) has changed。(A) changes 現在簡單式無法表達「累積至今」的語意；(B) changed 過去簡單式僅描述單一過去動作，不符合 since 引導的持續語境；(D) will change 未來式與句意不符。

**相關文法點**:
對應第 1 節「現在完成式」中「經驗」用法，常搭配 since + 過去時間點。

**相似題型提醒**:
注意 since 子句本身用過去式（was founded），主句才用現在完成式，是常考的時態搭配組合。

## 題目 2：過去完成式（by the time + 過去式）
**答案**: B

**詳細解析**:
"By the time the inspector arrived" 是 by the time 加過去式子句，表示「在檢查員抵達之前」，工人已經完成的動作應使用**過去完成式**，表達「過去的過去」。故選 (B) had / fixed。(A) have / fixed 現在完成式時態層次不對；(C) will have / fixed 未來完成式與過去時間軸矛盾；(D) has / fixed 現在完成式且單複數也不一致。

**相關文法點**:
對應第 2 節「過去完成式」：by the time + 過去式子句 ➔ 主句用過去完成式。

**相似題型提醒**:
by the time 子句的動詞時態決定主句時態：子句過去式 ➔ 主句過去完成式；子句現在式 ➔ 主句未來完成式（見題目 3）。

## 題目 3：未來完成式（by + 未來時間）
**答案**: C

**詳細解析**:
"by the end of this quarter" 是明確的未來時間點，表示「到某個未來時間點之前將完成的動作」，應使用**未來完成式**。故選 (C) will have implemented。(A) implement 現在簡單式不符合語意；(B) implemented 過去式時態錯誤；(D) had implemented 過去完成式與未來時間點矛盾。

**相關文法點**:
對應第 3 節「未來完成式」：by + 未來時間 ➔ will have + p.p.。

**相似題型提醒**:
by + 未來時間點（by 2027, by next Friday, by the end of...）幾乎是未來完成式的正字標記，务必快速辨識。

## 題目 4：have been to vs. have gone to
**答案**: A

**詳細解析**:
句意為「Ms. Lopez 今年已經去過柏林兩次（人現在不在柏林，已經回來了）」，強調的是「經驗、次數」，應使用 **have/has been to**。故選 (A) has been。(B) has gone 表示「去了、人目前還在該地」，與句子強調「兩次經驗」的語意不符；(C) went 過去簡單式無法搭配 twice this year 這種累計經驗的語意；(D) is going 現在進行式不符合已發生兩次的語境。

**相關文法點**:
對應「📚 補充秒殺公式」第 2 點：have/has been to（去過，已回來） vs. have/has gone to（去了，人還在那）。

**相似題型提醒**:
這是多益經典陷阱組合，務必牢記兩者差異：been to 強調經歷，gone to 強調目前人不在此處（在目的地）。

## 題目 5：短文填空（過去簡單式 + 未來完成式）
**答案**: (1) B　(2) C

**詳細解析**:
(1) "Since the company ... last spring" 中，since 引導的子句本身須使用**過去簡單式**描述過去某個確切時間點發生的動作，搭配主句 "have decreased"（現在完成式），形成 since + 過去式，主句 + 現在完成式 的標準結構，故選 (B) introduced。(A) introduces 現在簡單式與 last spring 明確過去時間矛盾；(C) has introduced 現在完成式不可用於 since 子句本身；(D) will introduce 未來式與句意不符。
(2) "By the end of this year" 是未來時間點，表示到那時管理層將已完成政策的全面檢討，應使用**未來完成式**，故選 (C) will have conducted。(A)(D) 為現在式/現在完成式，與 by the end of this year 的未來時間點不符；(B) had conducted 過去完成式時態錯誤。

**相關文法點**:
對應第 1 節「現在完成式」（since 子句用過去式）與第 3 節「未來完成式」（by + 未來時間）。

**相似題型提醒**:
篇章題常在同一段落中混合過去簡單式（since 子句）與未來完成式（by + 未來時間），需分別依各句的時間線索個別判斷，不能套用同一時態。
