# 10_need_want接doing表被動

## 核心概念
英文中有一組動詞——最常見的是 **need**、**want**、**require**——後面可以直接接 **V-ing**（動名詞），但意思卻是**被動**的。也就是說，`The report needs revising.` 這句話裡的 report 不是「去修改」的動作發出者，而是「被修改」的對象，意思等同於 `The report needs to be revised.`。這是多益文法題中一個容易被忽略、但辨識度很高的考點：看到 need/want/require + V-ing，要立刻反應成「主詞被…」。

## 1. 句型公式
**公式**：`S(事物) + need/want/require + V-ing = S(事物) + need/want/require + to be p.p.`

*   The printer **needs fixing**. = The printer **needs to be fixed**.
*   This contract **wants revising** before we sign it. = This contract **wants to be revised** before we sign it.
*   The old filing system **requires updating**. = The old filing system **requires to be updated**.（注意：require 較少用 to be p.p.，但意思相通）

## 2. 為什麼是被動意義？主詞是關鍵
這個句型只在**主詞是「事物」而非「人」**時才會出現被動解讀。如果主詞是人，need/want 後面接 V-ing 就只是單純的動名詞受詞，意思不會轉為被動。
*   事物當主詞（被動意義）：The office **needs cleaning**. (辦公室被打掃)
*   人當主詞（一般動名詞受詞，不是被動）：She **needs cleaning** the office. ← 這是錯誤句子！人當主詞時，need 後面若接動詞，只能用不定詞 `to V`，不能用 V-ing 表被動意義。
    *   正確：She **needs to clean** the office.

## 3. 三個常考動詞的細微差異
*   **need + V-ing**：最常見、最自然，口語與書面都通用。
*   **want + V-ing**：語感較口語、較強調「急需」，商業文件中偶爾出現，但正式度略低於 need。
*   **require + V-ing**：正式文件中出現，但更常見的仍是 `require + to be p.p.` 或 `require + that 子句`，考題中 require 接 V-ing 的頻率低於 need。

## 4. 常見混淆點
*   不要跟「動詞 + 受詞 + Ving」的句型（例如 catch/see/hear + O + Ving）搞混，那是感官動詞句型，受詞是「動作執行者」，不是被動。
*   不要跟「need/want + to V」搞混：`need/want + to V` 是一般不定詞用法，意思是「需要/想要去做某事」（主動），跟 `need/want + V-ing`（事物當主詞、被動意義）用法完全不同情境。

## 📚 補充秒殺公式
1.  **主詞辨識法**：看到「need/want + V-ing」，先確認主詞是不是「事物」（report, machine, office, system…）。是事物就是被動意義；是人就代表句子文法有誤，答案不該選 V-ing。
2.  **等價轉換公式**：`事物 + need/want + V-ing` 永遠可以改寫成 `事物 + need/want + to be p.p.`，兩者意思相同，考題常互相替換測驗理解。
3.  **選項判斷術**：若題目主詞是事物，空格前是 need/want，選項出現「原形動詞、V-ing、to V、p.p.」四種，優先鎖定 V-ing 或 to be p.p.；若只給 V-ing 和原形動詞兩個選項，V-ing 通常才是正解。
4.  **require 的例外**：require 接 V-ing 表被動的頻率遠低於 need/want，多益中 require 後面更常直接看到 `to be p.p.` 或 `that + S + (should) + V`，看到 require 時不要死背只選 V-ing。
5.  **同義代換片語**：`need/want + V-ing` 常可與 `be in need of + N`、`call for + N`、`stand in need of + N` 互相代換，閱讀測驗中常以片語形式改寫原句。
6.  **禁用陷阱**：`need/want + being p.p.`（例如 needs being fixed）是錯誤用法，多益不會考這種形式，看到選項有 being p.p. 直接刪除。
7.  **時態不受影響**：這個句型的時態變化只發生在 need/want 本身（needs / needed / will need），V-ing 部分永遠維持現在分詞形式，不隨時態改變。
8.  **搭配受詞的陷阱**：若 need/want 後面出現「受詞 + Ving」（如 needs him fixing it），那就不是本句型，而是不同結構甚至文法錯誤，要小心區分。
9.  **正式書面的替代寫法**：在正式商業文件中，`requires attention`、`requires immediate action` 等固定搭配也常出現，其中 attention/action 是名詞而非動名詞，不要與本句型混淆。
10. **否定與疑問句轉換**：否定時用 `doesn't need + V-ing`，疑問時用 `Does the machine need repairing?`，助動詞 do 的用法不受被動意義影響。
11. **與 deserve 的類比**：`deserve + V-ing` 也有類似的被動意義（The proposal deserves reviewing = deserves to be reviewed），可以用同樣的邏輯記憶，但 deserve 語氣偏向「值得」而非「必要」。
12. **閱讀測驗辨識線索**：文章中若出現「the outdated policy wants revising」這類句子，常暗示下一段會說明「將如何修訂」，是掌握文章邏輯走向的線索詞。

**1.** The aging server in the IT department badly needs ______ before it slows down the entire network.
(A) upgrade (B) upgrading (C) upgraded (D) to upgrading

**2.** Several clauses in the vendor agreement want ______ before the legal team can approve it.
(A) revised (B) revise (C) revising (D) to revise

**3.** According to the maintenance report, the packaging line requires ______ at least once every six months.
(A) inspect (B) inspecting (C) inspected (D) to inspecting

**4.** The outdated employee handbook needs ______ to reflect the company's new remote-work policy.
(A) rewrite (B) rewrote (C) rewriting (D) written

**5.** Ms. Alvarez, the new intern, needs ______ how to use the expense-reporting software.
(A) learning (B) to learn (C) learn (D) learned

**6.** The billing discrepancy from last month's invoices still wants ______ before the audit begins.
(A) sort out (B) sorting out (C) to sort out (D) sorted out

**7.** The security flaw discovered during the review needs ______ immediately, or the system will remain vulnerable.
(A) patch (B) patched (C) patching (D) to patching

**8.** Given the recent complaints, the customer service script clearly merits ______ before representatives use it again.
(A) rewording (B) reword (C) reworded (D) to reword

**9.** The finance director insisted that the entire budgeting process needs ______ to reduce approval delays.
(A) streamline (B) streamlined (C) streamlining (D) to streamlined

**10.** The torn seals on several returned packages need ______ before the items can be resold.
(A) mend (B) mended (C) mending (D) to mend

**11.** 第一空：The draft press release still needs ______ for a few grammatical errors.（第一空）第二空：Once it is polished, the outdated media contact list also wants ______ before it is sent out.（第二空）
(A) proofreading (B) updating

**12.** The vague wording in the return policy warrants ______, since several customers have misunderstood it.
(A) clarify (B) clarified (C) clarifying (D) to clarifying

**13.** The old inventory database needs ______, so the IT team scheduled the migration for this weekend.
(A) overhaul (B) overhauling (C) overhauled (D) to overhaul

**14.** Because the layout wastes so much floor space, the entire warehouse wants ______ before the new shipment arrives.
(A) reorganize (B) reorganized (C) reorganizing (D) to reorganizing

**15.** 第一空：The forecasting model the analysts built last year needs ______ to account for the recent market shift.（第一空）第二空：Once the figures are corrected, the summary chart will also need ______.（第二空）
(A) refining (B) updating
