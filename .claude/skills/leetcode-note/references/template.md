## 選配段落

### 多版本程式碼
`## 程式碼實作` 底下用 `###` 分節，目錄同步縮排：

```markdown
- [程式碼實作](#程式碼實作)
  - [原始 DFS 驗證版本](#原始-dfs-驗證版本)
  - [更簡潔版本：位置映射一次掃描](#更簡潔版本位置映射一次掃描)
```

注意：`：` 這類全形標點在錨點中會被刪除且不留空白，故為 `#更簡潔版本位置映射一次掃描`。

### 複雜度拆成兩節
目錄改為：

```markdown
- [時間複雜度分析](#時間複雜度分析)
- [空間複雜度分析](#空間複雜度分析)
```

### 延伸思考
放在常見誤區之後、小結之前。誤區段落要不要改名成「與補充」是**獨立決定**，兩種組合都合法：

```markdown
- [常見誤區](#常見誤區)
- [延伸思考](#延伸思考)
- [小結](#小結)
```

```markdown
- [常見誤區與補充](#常見誤區與補充)
- [延伸思考](#延伸思考)
- [小結](#小結)
```
