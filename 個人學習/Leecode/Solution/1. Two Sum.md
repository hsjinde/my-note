# Brute Force
```python!
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        for i in range(len(nums)):
            for j in range(i+1, len(nums)):
                if nums[i] + nums[j] == target:
                    return [i, j]
```
Time complexity: O($n^2$)
Space complexity: O(1)

# 計算差

```python!
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        # 遍歷陣列中的每個數字
        for i in range(len(nums)):
            # 計算當前數字的補數
            dif = target - nums[i]
            # 檢查補數是否在陣列中
            if dif in nums:
                # 如果補數存在，則找出它的索引
                j = nums.index(dif)
                # 確保不是同一個元素的索引
                if i != j:
                    # 回傳找到的兩個索引
                    return [i, j]

```
Time complexity: O($n^2$)，不是 O(n)。`dif in nums` 與 `nums.index(dif)` 各是一次 O(n) 線性掃描，包在 O(n) 的迴圈裡仍是平方級，只是掃描在 C 層執行、常數比 Brute Force 小。實測 n 從 2000 翻倍到 8000，耗時 26ms → 118ms → 401ms，正好是四倍成長。
Space complexity: O(1)

# Hash Table
```python!
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        dic = {}  # 建立一個空字典，用來存放數字及其索引
        for i in range(len(nums)):  # 遍歷陣列中的每個數字
            dif = target - nums[i]  # 計算當前數字的補數
            if dif not in dic:      # 如果補數不在字典中
                dic[nums[i]] = i    # 將當前數字及其索引加入字典
            else:
                return [i, dic[dif]]  # 如果補數在字典中，回傳當前索引與補數的索引

```
用空間換時間，把「找補數」從線性掃描降成 O(1) 的字典查詢，同一趟迴圈邊建表邊查表。
Time complexity: O(n)
Space complexity: O(n)
