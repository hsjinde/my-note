# 08_科技與IT情境 - 詳細解答

## 題目 1：介系詞（被動搭配）題
**答案**: A

**詳細解析**:
「be protected by + 手段/方式」是固定被動搭配，意為「被……所保護」，故選 **by**。(B) through 常表示「透過某管道／經由」，但不與 protected 搭配；(C) with 常用於「具備某工具」的語意（如 equipped with），與 protected 語意不合；(D) for 不表方式或手段。

**相似題型提醒**:
be covered by / be protected by / be secured by 等「被動 + by + 手段」的搭配，須與 with（具備）、through（經由過程）區分清楚。

## 題目 2：時態（過去完成式）題
**答案**: C

**詳細解析**:
句意為「在漏洞被公開揭露之前，IT 團隊已經安裝了修補程式」，before the vulnerability was publicly disclosed 是過去式子句，表示「揭露」發生在過去；而「安裝修補程式」發生在「揭露」之前，屬於「過去的過去」，須用**過去完成式** had installed。(A)(B)(D) 皆無法表達「比過去更早」的時間關係。

**相似題型提醒**:
before / by the time + 過去式子句，且主要子句動作發生在該過去時間點之前，優先考慮過去完成式 (had + p.p.)。

---

## 題目 3：關係代名詞（主格，先行詞為人）題
**答案**: C

**詳細解析**:
空格後面的子句 ______ discovered the critical vulnerability 缺少主詞，且先行詞 The engineer 是「人」，須用**主格關代** who。(A) which 用於先行詞是「物」；(B) whose 是所有格，後方須接名詞；(D) whom 是受格，用於子句中缺受詞的情況，此處子句缺的是主詞。

**相似題型提醒**:
判斷關代格位時，先看空格後方子句是否完整：缺主詞用主格（who/which），缺受詞用受格（whom/which），缺名詞用所有格（whose）。

---

## 題目 4：詞性（副詞）題
**答案**: C

**詳細解析**:
空格修飾動詞 verifies，須用**副詞**表達「更安全地驗證」，故選 securely。(A) secure 是形容詞；(B) security 是名詞；(D) securing 是動名詞/現在分詞，皆不可直接修飾動詞。

**相似題型提醒**:
動詞後方若已有受詞（user identity），額外的空格多半是副詞，用來修飾整個動作的方式，是詞性題最基本的判斷原則。

---

## 題目 5：連接詞 vs. 介系詞片語題
**答案**: A

**詳細解析**:
空格後接名詞片語 the sudden server crash（非完整子句），須用**介系詞** despite。(B) Although 與 (C)(D) Because/Unless 皆為連接詞，後方須接「主詞+動詞」的完整子句，不可直接接名詞片語。

**相似題型提醒**:
despite / in spite of（介系詞，接名詞）vs. although / even though（連接詞，接子句）是多益必考對比，務必先確認空格後方是名詞還是完整子句。

---

## 題目 6：分詞（過去分詞修飾名詞）題
**答案**: C

**詳細解析**:
空格修飾 The data breach，且「資料外洩」與「造成」是被動關係（外洩「被」某位離職員工所造成），須用**過去分詞** caused 形成分詞片語修飾名詞。(A) cause 是原形動詞，不可單獨修飾名詞；(B) causing 表主動，語意不合（資料外洩不會主動造成）；(D) to cause 不符合此處分詞片語用法。

**相似題型提醒**:
分詞片語修飾名詞時，判斷「主動用 V-ing」還是「被動用 p.p.」的關鍵在於：名詞與該動詞是「執行」還是「被執行」的關係。

---

## 題目 7：不定詞（advise + 受詞 + to V）題
**答案**: D

**詳細解析**:
advise + 受詞（employees）+ to V 是固定句型，表示「建議某人做某事」，故選 to change。(A)(B)(C) 皆非不定詞形式，不可接在此句型中。

**相似題型提醒**:
advise / encourage / remind / require + 受詞 + to V 是多益常考的一組動詞句型，須留意受詞後方固定接不定詞。

---

## 題目 8：名詞子句連接詞（how）題
**答案**: C

**詳細解析**:
determine 後方接名詞子句，說明「尚未查明惡意軟體『如何』繞過防火牆」，須用表示方式/手段的連接詞 **how**。(A) that 引導的子句需為肯定敘述，且不表方式；(B) what 通常指「什麼事物」，與此處問「方法」的語意不合；(D) which 需有明確選擇範圍，此處無此語境。

**相似題型提醒**:
determine / explain / investigate 後方常接 how（方式）、why（原因）、whether（是否）等名詞子句連接詞，須依語意選擇正確的疑問詞。

---

## 題目 9：假設語氣（recommend that + 原形動詞）題
**答案**: C

**詳細解析**:
recommend that 子句須用**虛擬語氣**，動詞一律用**原形**（不因主詞而變化，也不受時態影響），故選 adopt。(A) adopts 有第三人稱單數變化，不符合虛擬語氣；(B) adopted 是過去式；(D) adopting 是動名詞，皆不可作為 that 子句中的主要動詞。

**相似題型提醒**:
recommend / suggest / insist / require / demand + that + 主詞 + 原形動詞，是多益必考的「假設語氣」句型，動詞永遠用原形。

---

## 題目 10：比較級（far + 比較級）題
**答案**: B

**詳細解析**:
far 用來加強**比較級**的語氣，「far more sophisticated than」意為「遠比……更複雜精密」，故選 more。(A) most 是最高級，不與 than 連用；(C) much 雖也可加強比較級（much more），但此處已有 far，兩者功能重複，且題目結構 far + ______ + sophisticated + than 明確要求比較級形式 more；(D) very 不可修飾比較級。

**相似題型提醒**:
far / much / even / a lot + 比較級 + than，是加強比較語氣的固定搭配，須與最高級（most）或原級（very + 形容詞原級）區分。

---

## 題目 11：動名詞（介系詞 + V-ing）題
**答案**: C

**詳細解析**:
be responsible for 之後須接**動名詞**作為介系詞的受詞，故選 testing。(A) test 是原形動詞，不可直接接在介系詞後；(B) tested 是過去式/過去分詞；(D) to test 是不定詞，皆不可作介系詞受詞。

**相似題型提醒**:
介系詞（for / of / in / by 等）後方一律接動名詞或名詞，不可接原形動詞，是多益詞性題的基本規則。

---

## 題目 12：詞性（可數名詞單複數）題
**答案**: A

**詳細解析**:
空格前有不定冠詞 **a**，故須搭配**單數可數名詞** delay（一次延誤）。(B) delays 是複數形式，與 a 不搭配；(C) delayed 是過去式/過去分詞，不可作名詞使用；(D) delaying 是動名詞，語意上不會與 a significant 直接搭配作受詞。

**相似題型提醒**:
看到 a / an + 形容詞 + ______ 的結構時，空格須為**單數可數名詞**，須特別留意名詞的單複數形式是否與冠詞一致。
