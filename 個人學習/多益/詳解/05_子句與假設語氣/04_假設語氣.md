# 04_假設語氣 詳解

## 題目 1：與過去事實相反（If 子句過去完成式）
**答案**: B

**詳細解析**:
主要子句 "it would have avoided the product recall" 使用 `would have + p.p.`，代表這是「與過去事實相反」的假設語氣，If 子句應搭配**過去完成式** (had + p.p.)。(A) conducts 是現在式，(C) conducted 是過去式，(D) has conducted 是現在完成式，皆不符合過去事實相反的公式。故選 (B) had conducted。

**相關文法點**:
對應主章節「2. 與過去事實相反 (Past Unreal)」公式：`If + S + had + p.p., S + would/could/should/might + have + p.p.`

**相似題型提醒**:
先看主要子句（逗號後）的動詞形態，反推 If 子句應該用哪一種假設時態，是最快的解題捷徑。

---

## 題目 2：Should 開頭的倒裝句（與未來相反）
**答案**: A

**詳細解析**:
句首沒有 If，且句子結構是「助動詞 + 主詞 + 原形動詞」的倒裝形式，加上後面主要子句是祈使句 "please do not hesitate to contact"，符合「與未來相反/萬一」假設語氣的倒裝句型。(B) Would、(C) Were、(D) Had 均不符合此倒裝句型的語意與結構（Were 用於與現在事實相反的倒裝，Had 用於與過去事實相反的倒裝）。故選 (A) Should。

**相關文法點**:
對應主章節「考點 1：條件句的倒裝 (If 省略)」第 2 點「與未來相反倒裝 (最常考)：Should + S + V, 祈使句」。

**相似題型提醒**:
看到句首是 Should/Were/Had 且沒有 If，且句子呈現倒裝語序，優先判斷是哪一種倒裝假設句型，再對照後半句的動詞形式確認。

---

## 題目 3：I wish + 過去完成式（與過去事實相反）
**答案**: C

**詳細解析**:
句意是「我希望我在訂機票之前就已經知道班表變動」，這件事發生在過去（訂機票之前），且與過去事實相反（當時並不知道），wish 後面的子句應使用**過去完成式**。(A) know 是現在式，(B) knew 是過去式（用於 wish + 與現在事實相反），(D) have known 是現在完成式，均不符合。故選 (C) had known。

**相關文法點**:
對應補充秒殺公式第 2 點「I wish + 假設語氣」：與過去事實相反時，wish 後接過去完成式。

**相似題型提醒**:
wish 後面的假設語氣時態退一格的規則和 If 子句相同：與現在相反用過去式，與過去相反用過去完成式，需依句子的時間點判斷，不能只看 wish 本身的時態。

## 題目 4：短文填空 — 條件句現在式 vs. 過去完成式倒裝
**答案**:
(1) A
(2) B

**詳細解析**:
(1) 句意是「如果合併案在下個月獲得批准，兩家公司將立即開始整合系統」，主要子句使用未來式 "will begin"，代表這是「真實條件句」（可能發生的未來事件），If 子句依規則使用**現在式**代替未來式。(B) were 用於與現在事實相反的假設語氣，(C) had been 用於與過去事實相反，(D) will be 在真實條件句的 if 子句中不可用未來式。故選 (A) is。
(2) 句意是「分析師表示，萬一交易告吹，股東將會損失可觀的價值」，句首無 If，且呈現倒裝語序（助動詞/had + 主詞 + 過去分詞），對應「與過去事實相反」的倒裝句型 Had + S + p.p.。(A) if 若使用則不構成倒裝句，且句子會缺少倒裝應有的助動詞前移；(C) unless 語意「除非」不符；(D) once 語意「一旦」不符此假設語境。故選 (B) had。

**相關文法點**:
對應主章節「3. 與未來事實相反」的真實條件句時態規則，以及「考點 1：條件句的倒裝」第 1 點「與過去相反倒裝：Had + S + p.p., S + would have p.p.」。

**相似題型提醒**:
短文中常同時出現「真實條件句（現在式代未來式）」與「假設語氣倒裝句」兩種考點，須分別判斷每個空格所屬的句型，不要互相套用公式。

## 題目 5：Without（要不是因為...與過去事實相反）
**答案**: A

**詳細解析**:
句意是「要不是技術支援團隊，伺服器當機的時間會拖得更久」，主要子句使用 `would have lasted`，屬於與過去事實相反的假設語氣，句首可用 Without 或 But for 表示「要不是因為」。(B) Unless 意思是「除非」，且不能直接接名詞構成此句型；(C) If 若使用需改寫成完整子句 (If it had not been for...)，不能直接接名詞；(D) Despite 語意「儘管」，與「要不是」的邏輯不符。故選 (A) Without。

**相關文法點**:
對應主章節「考點 2：Without / But for (要不是因為...)」— 與過去相反：`Without / But for + N, S + would have + p.p.`

**相似題型提醒**:
Without/But for 可與 Had it not been for 互換使用（見補充秒殺公式），三者皆表達「要不是因為」，但 Had it not been for 是完整倒裝子句，Without/But for 後面直接接名詞，注意句型結構差異。

## 題目 6：與現在事實相反（主句）
**答案**: B

**詳細解析**:
if 子句用 `were`，屬於**與現在事實相反**的假設 ➔ 主句要用 `would/could/might + 原形動詞` **would drop**(B)。(A) 是直述未來式；(C) 是過去式；(D) 是現在完成式。

**相關文法點**:
對應「1. 與現在事實相反 (Present Unreal)」：`If + S + 過去式, S + would + V`。

**相似題型提醒**:
與現在相反時 be 動詞一律用 `were`，不分人稱。看到 `If I were…`、`If it were…` 就要在主句找 would + 原形。

---

## 題目 7：與過去事實相反（主句被動）
**答案**: B

**詳細解析**:
if 子句是 `had + p.p.`，屬於**與過去事實相反** ➔ 主句用 `would have + p.p.`，被動則是 `would have been + p.p.` ➔ **would have been avoided**(B)。(A) 是與現在相反的形式；(C) 是直述未來；(D) 是過去完成被動。

**相關文法點**:
對應「2. 與過去事實相反 (Past Unreal)」：`If + S + had p.p., S + would have p.p.`

**相似題型提醒**:
主句與子句的時態是配對的：過去式配 would V、過去完成式配 would have p.p.。先看 if 子句就能鎖定主句形式。

---

## 題目 8：與過去事實相反（if 子句）
**答案**: C

**詳細解析**:
主句是 `could have been contained`，代表這是**與過去事實相反** ➔ if 子句要用過去完成式 **had noticed**(C)。(A) 是現在式；(B) 是過去式，那是與現在相反的形式；(D) if 子句中不用 would。

**相關文法點**:
對應「2. 與過去事實相反 (Past Unreal)」的條件句公式。

**相似題型提醒**:
if 子句裡永遠不出現 would——這是最容易被中文語感帶偏的地方。would 只出現在主句。

---

## 題目 9：But for 表「要不是因為」
**答案**: A

**詳細解析**:
主句是 `would have shut down`，屬於與過去事實相反；`But for + 名詞` 等於「要不是因為…」➔ **But for**(A)。(B) Except、(C) Apart、(D) Aside 都無法單獨構成這個假設結構。

**相關文法點**:
對應「考點 2：Without / But for (要不是因為...)」：與過去相反時搭配 would have + p.p.。

**相似題型提醒**:
`But for` 與 `Without` 完全同義，兩者都後接名詞。主句用 would V 或 would have p.p.，取決於假設的是現在還是過去。

## 題目 10：與現在事實相反（主句用 could）
**答案**: B

**詳細解析**:
if 子句用 `were`，是與現在事實相反 ➔ 主句用 `could + 原形動詞` **could produce**(B)。(A) can 是直述語氣；(C) 是與過去相反的形式；(D) 是過去式。

**相關文法點**:
對應「1. 與現在事實相反」：主句可用 would/could/should/might + 原形動詞。

**相似題型提醒**:
主句的助動詞可以換（would 表意願、could 表能力、might 表可能），但一律接**原形動詞**，這點不變。

---

## 題目 11：與過去相反的倒裝句（主句）
**答案**: C

**詳細解析**:
句首 `Had the revised terms included…` 是省略 if 的**倒裝**，等於 `If the revised terms had included…`，屬於與過去事實相反 ➔ 主句用 **would have accepted**(C)。(A) 是直述未來；(B) 是與現在相反；(D) 是過去式。

**相關文法點**:
對應「考點 1：條件句的倒裝 (If 省略)」：`Had + S + p.p., S + would have p.p.`

**相似題型提醒**:
看到句首是 Had / Were / Should 加主詞，就要意識到 if 被省略了，接著依照倒裝的形式決定主句時態。

---

## 題目 12：as if 加假設語氣（與過去相反）
**答案**: C

**詳細解析**:
`as if` 引導與事實相反的假設；語意是「彷彿她之前親手寫過」，指向**更早的過去** ➔ 用過去完成式 **had written**(C)。(A) 是現在式；(B) 過去式表示與現在相反；(D) 假設語氣的子句不用 would。

**相關文法點**:
對應假設語氣在 as if 子句中的運用：與現在相反用過去式，與過去相反用過去完成式。

**相似題型提醒**:
`as if + 過去式`（彷彿現在是…）與 `as if + 過去完成式`（彷彿之前曾…）的差別，就在假設的時間點。

---

## 題目 13：混合條件句（過去條件、現在結果）
**答案**: B

**詳細解析**:
if 子句講的是**過去**（had diversified），主句的 `today` 指向**現在的結果** ➔ 主句用 `would + 原形動詞` **would be**(B)。(C) would have been 用於結果也在過去的情況；(A) 與 (D) 是直述語氣。

**相關文法點**:
對應「1. 與現在事實相反」與「2. 與過去事實相反」的組合：條件在過去、結果在現在。

**相似題型提醒**:
混合條件句的判斷靠時間副詞：主句出現 `today`, `now` 就用 would V；出現 `then`, `at that time` 才用 would have p.p.。

---

## 題目 14：與未來相反的倒裝（Were + S + to V）
**答案**: B

**詳細解析**:
`Were + S + to V` 是 `If + S + were to V` 的倒裝，表示對未來的假設 ➔ 主句用 `would + 原形動詞` **would revise**(B)。(A) 是直述未來；(C) 是過去式；(D) 是現在完成式。

**相關文法點**:
對應「考點 1：條件句的倒裝」：`Were I the manager, I would fire him.`

**相似題型提醒**:
`were to` 用來強調「假使真的發生」的低可能性。倒裝後把 Were 提到句首，主句形式與一般假設語氣相同。

---

## 題目 15：Should 倒裝搭配祈使句主句
**答案**: B

**詳細解析**:
`Should + S + V` 是 `If + S + should + V` 的倒裝，主句常搭配**祈使句** ➔ 用原形動詞開頭 **notify**(B)。(A) 是動名詞；(C) 是不定詞；(D) 是過去分詞。

**相關文法點**:
對應「考點 1：條件句的倒裝」第 2 點：`Should you need further assistance, please let us know.`

**相似題型提醒**:
這是多益商務書信最高頻的假設語氣句型。主句除了祈使句，也可以是 `will/can + 原形動詞`。
