# 模擬測驗四 - 詳細解答

## Part 5：單句文法與字彙填空

## 題目 1：so...that 句型
**答案**: A

**詳細解析**:
**so + 形容詞/副詞 + that** 表示「如此…以致於…」，空格後為形容詞 successful，須用 so。(B) such 須接「such + (a/an) + 形容詞 + 名詞 + that」，其後若無名詞則不可用 such；(C) too 表示「太…以致於不能」，後方通常接 to V 而非 that 子句，且語意為負面結果，與句意不合；(D) very 只能修飾原級形容詞，無法與 that 子句構成因果句型。

**相關文法點**: so...that 與 such...that 的結構差異（so + adj/adv vs. such + (a/an) + adj + N）。

**相似題型提醒**: 題庫中另有一題（題目 13）同樣測試 so/such 的辨析，但該題空格後為形容詞 visible 而非名詞，判斷原則相同：若後方緊接的是形容詞或副詞，一律用 so，不可誤選 such。

## 題目 2：關係代名詞（所有格）
**答案**: C

**詳細解析**:
空格後方為名詞 names，且 names 是指「店經理的名字」，句子隱含「their names」的所有關係，須用**所有格關係代名詞** whose。(A) who 為主格，後面不可直接接名詞；(B) which 雖可指物，但同樣不可直接接名詞作所有格用法；(D) that 亦為主格/受格關代，無所有格用法。

**相關文法點**: whose 用於先行詞與空格後名詞構成「所有」關係，無論先行詞為人或物皆可使用。

**相似題型提醒**: 題庫中已有多題測試「先行詞, ______ 動詞...」的一般主格關代用法（如 handbook, which was distributed...），本題刻意改考所有格關代 whose，須注意空格後方緊接名詞、而非動詞，是辨識所有格關代的關鍵線索。

## 題目 3：使役動詞（have + O + p.p.）
**答案**: B

**詳細解析**:
**have + 受詞 + 過去分詞**表示「請人做某事／使某事被完成」，storefront display 與 redesign 為**被動關係**（展示櫥窗被重新設計），故選 redesigned。(A) redesign 為原形動詞，若用於 have + O + V 表示受詞主動執行該動作，但展示櫥窗不會主動「重新設計」；(C) to redesign 不符合 have 使役動詞後接原形或過去分詞的文法規則；(D) redesigning 為現在分詞，語意上不符合被動完成的情境。

**相關文法點**: 使役動詞 have/make/get 後接受詞的分詞選用原則：受詞與動作為主動關係用原形動詞，被動關係用過去分詞。

**相似題型提醒**: 題庫中已出現多題 have/make + O + V 原形的使役句型（如 make the cashiers verify），本題與題目 12 的差異在於受詞和動作之間是被動關係還是主動關係，作答時務必先判斷受詞是「執行動作」還是「被施加動作」。

## 題目 4：no matter how 倒裝結構
**答案**: A

**詳細解析**:
**no matter how + 形容詞/副詞 + 主詞 + 動詞**表示「無論多麼…」，此處修飾的是名詞 a discount 前的性質，且句構為 how + 形容詞 + a + 名詞（generous a discount），須用**形容詞** generous。(B) generously 為副詞，不能直接修飾名詞 discount；(C) generosity 為名詞，不符合 how 後接形容詞/副詞的文法；(D) more generous 為比較級，与 no matter how 的固定用法不符（no matter how 後接原級）。

**相關文法點**: no matter how + adj/adv 引導的讓步子句；how + adj + a + N 的特殊詞序。

**相似題型提醒**: 此為題庫中首次出現的 no matter how 句型，與常見的 despite/although 讓步句型（如題目庫中大量出現的 Despite the... 句型）功能相近但結構不同，須特別注意 no matter how 後面要接「形容詞/副詞」而非直接接名詞片語。

## 題目 5：動名詞（enjoy + V-ing）
**答案**: C

**詳細解析**:
**enjoy** 為固定接**動名詞**作受詞的動詞，表示「樂於做某事」，故選 discussing。(A) discuss 為原形動詞，不可直接作 enjoy 的受詞；(B) to discuss 為不定詞，enjoy 不接不定詞；(D) discussed 為過去式/過去分詞，不符合作受詞的文法需求。

**相關文法點**: enjoy、consider、suggest、avoid 等動詞後須接動名詞作受詞，不可接不定詞。

**相似題型提醒**: 題庫中已有 suggest + V-ing、mind + V-ing 等動名詞受詞題型，本題以 enjoy 測試相同觀念，凡遇到「動詞 + 受詞」結構時，須先確認該動詞的固定搭配是動名詞還是不定詞。

## 題目 6：主詞動詞一致（each of + 複數名詞）
**答案**: B

**詳細解析**:
**each of + 複數名詞**作主詞時，動詞須用**單數**，因為 each 本身為單數概念，故選 is。(A) are、(C) were、(D) have been 皆為複數動詞形式，與 each 的單數性質不合；且句子語境為現在正在進行的規定（this month），過去式 were 亦不符合時態。

**相關文法點**: each / every / either / neither + of + 複數名詞，動詞一律用單數。

**相似題型提醒**: 題庫中已出現 Each applicant must submit... 等 each 作為形容詞修飾單數名詞的題型，本題改考 each of + 複數名詞的用法，兩者動詞皆須用單數，但結構不同，作答時須注意 each 後方是否接 of。

## 題目 7：與過去事實相反的假設語氣（省略 if 倒裝）
**答案**: C

**詳細解析**:
句首 Had the retailer launched... 為**省略 if 的倒裝句**，等於 If the retailer had launched...，屬於**與過去事實相反**的假設語氣，主要子句須用 **would have + p.p.**，故選 would have been。(A) would be 用於與現在事實相反的假設；(B) will be 為直說語氣的未來式，不符合假設語氣；(D) had been 缺少 would，不能單獨作主要子句動詞。

**相關文法點**: 與過去事實相反假設語氣：If S had p.p., S would have p.p.；倒裝形式 Had S p.p., S would have p.p.。

**相似題型提醒**: 題庫中已有 If the company had done more research, it would have avoided... 等相同句型的一般形式，本題改為倒裝形式（省略 if，Had 提前），本質相同，須熟悉兩種呈現方式皆可能出現。

## 題目 8：詞性（形容詞修飾主詞補語）
**答案**: A

**詳細解析**:
**look + 形容詞**表示「看起來…」，look 為連綴動詞，其後須接**形容詞**作主詞補語，故選 eye-catching（醒目的、吸睛的）。(B) eye-catchingly 為副詞，不可作連綴動詞後的補語；(C) eye-catch 並非正確詞形；(D) eye-catchers 為名詞複數，雖文法上可作補語，但語意為「某些吸引目光的人/物」，與句意「展示看起來很醒目」不符。

**相關文法點**: look / seem / appear / become 等連綴動詞後接形容詞作主詞補語，不可用副詞。

**相似題型提醒**: 此為題庫中首次以 look + adj 測試連綴動詞句型，觀念與一般「主詞 + be動詞 + 形容詞」相同，須注意連綴動詞之後一律接形容詞，而非副詞。

## 題目 9：對等連接詞（either...or）
**答案**: C

**詳細解析**:
固定搭配 **either...or...**表示「不是…就是…」，句中已出現 either，後方須搭配 **or** 呼應，故選 C。(A) but、(B) nor、(D) so 皆無法與 either 搭配構成正確的對等連接詞組合（nor 須搭配 neither）。

**相關文法點**: either...or / neither...nor 為固定搭配，不可混用。

**相似題型提醒**: 題庫中已有 not only...but also 的對等連接詞題型，本題改考 either...or，作答原則相同：看到句中已出現的關聯詞，即可鎖定唯一能與之呼應的另一半。

## 題目 10：反身代名詞（強調用法）
**答案**: C

**詳細解析**:
此處 herself 緊接在主詞 the store manager 之後，作**強調用法**，表示「店經理本人親自」，故選 herself。(A) she 為主格，重複使用主詞不合文法；(B) hers 為所有格代名詞，語意不合；(D) her own 表示「她自己的（所有物）」，通常後接名詞，不能單獨作強調主詞的用法。

**相關文法點**: 反身代名詞的強調用法：主詞/受詞 + 反身代名詞，用來強調「本人親自」。

**相似題型提醒**: 此為題庫中首次測試反身代名詞的強調用法，與反身代名詞作受詞的一般用法（如 pride oneself on）不同，須注意此處 herself 並非作受詞，而是緊跟在名詞後方加強語氣。

## 題目 11：關係代名詞（非限定用法）
**答案**: C

**詳細解析**:
空格前有逗號，引導**非限定用法**的關係子句，先行詞 the seasonal catalog 為物，且子句中缺少主詞，須用**主格關係代名詞** which。(A) it 為代名詞，不能引導子句；(B) what 本身已包含先行詞，不可再接先行詞使用；(D) whom 為受格關代且只能指人，皆不符合。

**相關文法點**: 非限定用法關係子句（逗號 + which/who），先行詞為物時用 which。

**相似題型提醒**: 此類「先行詞, ______ 動詞...」的非限定關代題型在題庫中已多次出現（如 handbook, which was distributed），屬於重複度高的核心考點，須熟記逗號後先行詞為物一律用 which，不可用 that。

## 題目 12：使役動詞（make + O + V 原形）
**答案**: A

**詳細解析**:
**make + 受詞 + 原形動詞**表示「使／讓某人做某事」，收銀員與 verify 為**主動關係**（收銀員主動核對折扣碼），故選原形動詞 verify。(B) to verify 不符合 make 使役動詞後接原形動詞的文法；(C) verifying 為現在分詞；(D) verified 為過去分詞，皆不符合此使役句型的固定用法。

**相關文法點**: 使役動詞 make/have/let 後接受詞 + 原形動詞，表示主動去做某動作。

**相似題型提醒**: 本題與題目 3 皆測試使役動詞句型，但題目 3 的受詞與動作為被動關係（須用過去分詞），本題受詞主動執行動作（須用原形動詞），兩題並列可作為對照練習，判斷關鍵在受詞與動作間是主動還是被動。

## 題目 13：so...that 句型（形容詞在前）
**答案**: A

**詳細解析**:
**so + 形容詞 + that**表示「如此…以致於…」，空格後為形容詞 visible，須用 so。(B) such 須接名詞（such + a/an + adj + N），此處後方無名詞可接；(C) very 只能修飾原級形容詞，無法與 that 子句形成因果關係；(D) too 表示「太…而不能」，通常接 to V，且語意為負面阻礙，與句意（招牌明顯到讓顧客容易找到入口）不符。

**相關文法點**: so + adj + that 子句表示「如此…以致於」的因果句型。

**相似題型提醒**: 本題與題目 1 為同類型的 so/such 辨析題，皆測試「so 後方接形容詞、such 後方須接名詞」的核心原則，兩題並列有助於加深印象，避免只記住表面上的「so 或 such」而忽略後方詞性的判斷依據。

## 題目 14：主詞動詞一致（who 子句先行詞為複數）
**答案**: B

**詳細解析**:
who 引導的形容詞子句修飾先行詞 customers（複數），子句中缺主詞，動詞須與先行詞的**數**一致，故用複數動詞 accumulate。(A) accumulates 為單數動詞，與複數先行詞 customers 不一致；(C) accumulating 為現在分詞，不能單獨作子句的主要動詞；(D) to accumulate 為不定詞，同樣不能作子句的主要動詞。

**相關文法點**: 關係子句中的動詞須與先行詞的單複數一致，而非與主要子句的主詞一致。

**相似題型提醒**: 此類考點容易與一般主詞動詞一致的題型（如 each of + 複數名詞用單數動詞）混淆，須特別注意本題的動詞一致對象是「先行詞 customers」，而非空格所在子句以外的其他名詞。

## 題目 15：詞性（副詞修飾被動語態動詞）
**答案**: B

**詳細解析**:
空格修飾被動語態動詞片語 was distributed（被分發），須用**副詞** widely（廣泛地）。(A) wide 為形容詞或作副詞使用時多指「寬」的物理距離（如 open wide），語意不符；(C) widen 為動詞，「使變寬」，不符合此處需要副詞修飾動詞的文法；(D) width 為名詞，不可修飾動詞。

**相關文法點**: 副詞修飾被動語態動詞（be + p.p. + adv），表示動作進行的方式或程度。

**相似題型提醒**: 題庫中已有 track their shipments conveniently、proceeded smoothly 等副詞修飾動詞的題型，本題延續相同考點，差異在於本題修飾的是被動語態動詞，須注意副詞在被動語態中通常置於過去分詞之後。

## 題目 16：分詞作形容詞（過去分詞修飾名詞）
**答案**: C

**詳細解析**:
All ______ items 中，空格修飾名詞 items，且商品與「挑選」之間為**被動關係**（被挑選出來的商品），須用**過去分詞** selected。(A) select 為原形動詞，不可單獨修飾名詞；(B) selects 為第三人稱單數動詞，不可作形容詞使用；(D) selecting 為現在分詞，表示主動進行的動作，與商品被動被挑選的語意不合。

## 題目 17：語意連接詞（附加語意）

### 短文二：客戶關係電子郵件

## 題目 20：比較級的強調用法
**答案**: B

**詳細解析**:
修飾比較級 a wider selection，須用可修飾比較級的副詞 **much**（…得多）。(A) far 雖然也可修飾比較級（far more），但此處後方為「a wider selection」，much wider 為更常見且自然的固定搭配；(C) very 只能修飾原級形容詞，不能修飾比較級；(D) most 為最高級用法，與句中的比較級 wider 不搭配。

## 題目 21：時態（未來被動式）
**答案**: C

**詳細解析**:
句意為「你的帳戶『將會』被加值 500 點」，動作尚未發生但即將完成，且帳戶與「加值點數」為**被動關係**，須用**未來被動式** will be credited。(A) credit 為原形動詞，未表達被動或未來語意；(B) credits 為現在式主動動詞，與帳戶被動接受點數的語意不合；(D) crediting 為現在分詞，不能單獨作句子的主要動詞。

**相關文法點**: 未來被動式：will be + p.p.，表示未來將發生的被動動作。

**相似題型提醒**: 題庫中已有 will be moved up、was distributed 等被動語態題型，本題結合未來式與被動語態，須注意當主詞是動作的承受者且動作尚未發生時，須用 will be + p.p. 的形式。
