## 各專案摘要

### CORE PULSE
個人品牌網站本身即作品。重點在 Edge-Native 雙運行時（React SPA + Pages Functions）、`/telemetry` 的 Three.js WebGL 觀測台與 code-splitting 取捨，以及用 Playwright 把無障礙焦點環、SEO sitemap 同步、CSP 主題載入寫成 CI 契約——路由沒進 sitemap 就 build fail。

### my-note-web
把這個 Obsidian Vault 接上公開網頁。核心是 Sharded KV 儲存模型（整站導覽壓成一次 KV 讀取）、Webhook 增量同步 + Tarball 全量災難復原雙管線、GitHub Contents API 樂觀鎖回寫防覆蓋，以及不養 Vector DB 的全記憶體 Bigram 兩階段計分 RAG。15 個測試檔、83 個測試。

### 大阪旅券 OSAKA TRIP
Obsidian Markdown 當單一資料來源，CI 建置成靜態站；收藏與待辦狀態走 Cloudflare D1，斷線退回 localStorage、連線後補送。設計上是「御朱印帳」意象的完整設計系統，朱印紅填色面積硬性限制 ≤10%。Zod 在建置期擋掉格式錯誤的 Frontmatter。

### Osaka Vault
知識庫本身的工程化：原始剪藏層唯讀、AI 只寫 wiki 層，避免 LLM 污染 grounding 來源；圖片全部搬到 Cloudflare R2 並強制 ASCII key（解掉 Worker URL 解碼 404）；用 `wiki/log.md` 的 timestamp + 7 天 TTL 做增量消化，省掉重複燒 token。行程草稿以已付款訂單為最高真值，未確認項目一律標「待定 📌」。

### Postfix Manager
自架郵件伺服器的管理層。三個可談的硬點：用 Nginx `ngx_stream_module` 做四層 SSL Stream 繞過主機商封鎖的郵件埠；Django 介面自動化多網域 TLS + OpenDKIM 金鑰 + DNS 記錄編排；以及查出 Fail2ban 規則掛在 `INPUT` 鏈卻被 Docker DNAT 繞過、改掛 `DOCKER-USER` 鏈才生效。**本篇已脫敏**，實際埠映射、主機商與封鎖網段面試時再補。
