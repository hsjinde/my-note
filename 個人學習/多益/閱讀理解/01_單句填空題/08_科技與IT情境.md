# 08_科技與IT情境

## 📝 答題策略
1. **科技情境常考被動語態**：資安漏洞、系統升級、資料外洩等事件多半以「被動」呈現（系統被入侵、漏洞被發現），先判斷主詞與動詞是主動還是被動關係。
2. **看到 recommend / advise / insist 等動詞** ➔ 留意其後子句是否要求「原形動詞」（假設語氣）或不定詞（to V），兩者用法不同，不可混淆。
3. **看到 far + 比較級** ➔ far 用來加強比較級語氣（far more effective），不可用 far most 或 far very。
4. **空格前後有 responsible for / advised to 等固定搭配時** ➔ 優先確認介系詞後方該接動名詞還是不定詞後該接原形動詞，不要單憑語意猜測。
5. **關係代名詞題先看先行詞是人是物**，再看空格在子句中的角色（主詞、受詞、所有格）。
