# 09_讓步條件副詞子句 - 詳細解答

## 題目 1：even if vs. even though
**答案**: A

**詳細解析**:
子句描述「併購已經比預期花更久時間」，且主句用現在完成進行式 (have already begun) 說明這是已經發生的事實，因此應選表示「雖然（已是事實）」的 **even though**。若選 even if，語意會變成「就算併購花更久時間（尚未確定）」，與主句已經在整合系統的事實矛盾。unless（除非）與 in case of（以防）在語意及詞性（in case of 是介系詞片語，後面不能直接加完整子句）上都不合。

**相關文法點**:
對應正文「2. even if vs. even though 深度辨析」。

**相似題型提醒**:
判斷 even if / even though 時，先看子句敘述的事件是「已發生的事實」還是「尚未發生的假設」，再決定用哪一個。

## 題目 2：unless 的用法
**答案**: D

**詳細解析**:
句意為「除非財務部確認已全額付款，否則供應商不會放行貨物」，主句已經是否定 (will not release)，若選 even though 或 granted that 語意不通。whereas 表對比，也不符合語境。正確答案為 **unless**，表示「除非」，等於 if...not。

**相關文法點**:
對應正文「3. unless / in case / only if 三者比較」。

**相似題型提醒**:
`unless` 後面的子句本身不能再加 not，注意雙重否定陷阱。

---

## 題目 3：in case 表預防
**答案**: B

**詳細解析**:
句子描述物流團隊「事先準備一輛備用卡車」，是一種預防性措施，而不是「如果車輛故障才準備」，因此應選 **in case**（以防萬一）。若選 if，語意會變成「如果車輛故障，就備用卡車待命」，時態邏輯上不通順（備用卡車是提前準備好的）。unless（除非）與 only if（只有...才）在語意上都不符合「預先防範」的概念。

**相關文法點**:
對應正文「3. unless / in case / only if 三者比較」及 [!warning] in case 不是 if 提示框。

**相似題型提醒**:
`in case` 後面的動作是「預先準備」，常與 keep / bring / prepare 等動詞搭配，和單純表條件的 if 要區分清楚。

## 題目 4：only if 倒裝
**答案**: C

**詳細解析**:
句首為 ______, 後面主句用了倒裝結構 "will the board approve"，這是 **only if** 放句首時的典型倒裝現象（Only if + 子句, 助動詞 + 主詞 + 原形動詞...）。even if、in case、whether 都不會觸發這種倒裝規則。

**相關文法點**:
對應正文「3. unless / in case / only if 三者比較」。

**相似題型提醒**:
凡看到句首是強調用的否定/限定副詞（only, never, rarely, not until 等），要留意主句是否需要倒裝。

---

## 題目 5：no matter how 接形容詞/副詞
**答案**: B

**詳細解析**:
空格後面直接接形容詞 complicated，是 **no matter how** 的固定搭配（no matter how + 形容詞/副詞 + S + V），意思是「不管...多麼」。whereas 和 although 是完整連接詞但不能直接接 how，even 則需搭配 if/though 才能構成連接詞。

**相關文法點**:
對應正文「4. no matter + 疑問詞／whatever 系列」。

**相似題型提醒**:
`no matter how` 後面一定接形容詞或副詞，`no matter what` 後面才能接完整名詞片語，兩者不可混用。

---

## 題目 6：granted (that) 的讓步語氣
**答案**: A

**詳細解析**:
句意為「姑且承認這項提案風險不小，投資委員會仍決定推動」，這種「先承認、再轉折」的語氣正是 **granted that** 的典型用法。unless（除非）、in case（以防）、only if（只有...才）都無法表達這種讓步後轉折的邏輯。

**相關文法點**:
對應正文「5. 正式條件片語：granted (that) / on condition that / provided (that)」。

**相似題型提醒**:
`granted (that)` 常出現在正式報告或論述中，先承認對方論點的合理性，再提出自己的立場，是讓步子句常見的修辭手法。

---

## 題目 7：on condition that 表附帶契約條件
**答案**: B

**詳細解析**:
句意為「供應商同意降價，條件是零售商須完全透過新的線上入口下單」，這是典型的契約附帶條件，應選 **on condition that**。notwithstanding 是介系詞（儘管），albeit 後面只能接片語不能接完整子句，lest（以免）語意也不符合「降價的交換條件」。

**相關文法點**:
對應正文「5. 正式條件片語：granted (that) / on condition that / provided (that)」。

**相似題型提醒**:
`on condition that` 常見於合約、協議語境，強調「附帶條件才成立」，比 provided that 更契約導向。

---

## 題目 8：albeit 接片語
**答案**: C

**詳細解析**:
空格後面是形容詞片語 "minor ones that did not affect the final figures"，而非完整子句，因此應選 **albeit**（雖然，接片語）。unless、granted that、in case 後面都需要接完整子句 (S+V)，詞性不合。

**相關文法點**:
對應正文「6. 書面轉折／讓步副詞：albeit / notwithstanding / nevertheless / nonetheless」。

**相似題型提醒**:
`albeit` 是連接詞家族中的特例，後面接形容詞、分詞或介系詞片語，不能直接接「主詞+動詞」的完整子句。

---

## 題目 9：notwithstanding 作介系詞
**答案**: D

**詳細解析**:
空格後面接名詞片語 "the objections raised by two board members"，且句意為「儘管有反對意見，併購協議仍如期簽署」，應選介系詞 **notwithstanding**。even though 是連接詞，後面須接完整子句而非單純名詞片語；unless、provided 語意也不符合「儘管」的讓步概念。

**相關文法點**:
對應正文「6. 書面轉折／讓步副詞：albeit / notwithstanding / nevertheless / nonetheless」。

**相似題型提醒**:
`notwithstanding` 是少數可以「後置」的介系詞之一，也可以寫成 "The objections notwithstanding, ..."，兩種語序都要能辨認。

---

## 題目 10：nevertheless 銜接兩個獨立句子
**答案**: B

**詳細解析**:
句子用分號連接兩個獨立子句，第二句需要一個「副詞」來銜接語意上的轉折（營收大跌，然而公司仍避免裁員），應選 **nevertheless**。unless、granted that、in case 都是連接詞或連接詞片語，無法用來銜接分號後的獨立句子。

**相關文法點**:
對應正文「6. 書面轉折／讓步副詞：albeit / notwithstanding / nevertheless / nonetheless」。

**相似題型提醒**:
`nevertheless` / `nonetheless` 是副詞，不能像連接詞一樣直接連接兩個子句，前面通常需要句號或分號。

---

## 題目 11：no matter what 接完整名詞子句
**答案**: C

**詳細解析**:
空格後面是完整的名詞子句 "what feedback the pilot group provides"，語意為「不管試行小組提供什麼意見」，應選 **no matter**（搭配 what 構成 no matter what）。even if、unless、provided that 語意或結構皆不符合此處「不管...」的讓步語氣。

**相關文法點**:
對應正文「4. no matter + 疑問詞／whatever 系列」。

**相似題型提醒**:
`no matter what` 後面可以直接接一個完整的名詞子句作為讓步子句的核心，等同於 whatever。

---

## 題目 12：in order to 表目的
**答案**: C

**詳細解析**:
空格後面是原形動詞 "minimize"，句意為「為了將對日間營運的影響降到最低」，應選表目的的 **in order to**。for fear that 與 lest 都是「以免」的意思，且後面須接完整子句而非不定詞；notwithstanding 是介系詞，語意也不符。

**相關文法點**:
對應正文「7. lest 與 for fear that（否定目的／預防）」。

**相似題型提醒**:
`in order to` 表達「正面目的」，`lest` / `for fear that` 則表達「為了避免」，兩者方向相反，且後者需接完整子句。

---

## 題目 13：lest 接原形動詞
**答案**: D

**詳細解析**:
句意為「安全人員反覆檢查每個閥門，以免發生外洩」，空格後面用原形動詞 occur（省略 should），是 **lest** 的典型用法。even though、granted that、whereas 在語意或結構上都不符合這種「以免」的預防語氣。

**相關文法點**:
對應正文「7. lest 與 for fear that（否定目的／預防）」。

**相似題型提醒**:
`lest` 後面接原形動詞或 should + 原形動詞，屬於較正式、書面的用法，常見於安全規範或警告語句。

## 題目 14：雙格題 — although 與 notwithstanding
**答案**: 第一空：(C) 第二空：(B)

**詳細解析**:
第一空：句意為「客戶接受了修訂後的時程，雖然她仍對增加的成本感到擔憂」，前後兩件事同時為真且帶有對比意味，應選連接詞 **although**。unless、granted that、whether 語意或結構皆不合。
第二空：空格後面接名詞片語 "the concerns"，句意為「儘管有這些疑慮，她當天下午仍簽署了修訂後的合約」，應選介系詞 **notwithstanding**。unless、only if、even if 皆需接完整子句或條件語意，與此處純粹表「儘管」的語感不符。

**相關文法點**:
對應正文「6. 書面轉折／讓步副詞：albeit / notwithstanding / nevertheless / nonetheless」。

**相似題型提醒**:
雙格題常會同時考「連接詞」與「介系詞」的辨析，即使語意相近（都表讓步），也要依空格後面接的是子句還是名詞片語來決定詞性。

## 題目 15：whether or not 表不論
**答案**: B

**詳細解析**:
句子結構 "______ or not either party formally requests..." 是 **whether or not** 的固定搭配，意思是「不論是否」。unless（除非）、granted（就算，且通常接 that）、provided（只要，且通常接 that）在此結構中都不符合語意與句型。

**相關文法點**:
對應正文「🔤 相關單字和片語」中的 whether or not 詞條。

**相似題型提醒**:
`whether ... or not` 是固定句型，or not 可以緊跟在 whether 後面，也可以移到子句最後（whether either party requests... or not），兩種寫法都要能辨認。
