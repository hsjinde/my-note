# 06_物流與供應鏈情境

## 📝 答題策略
物流與供應鏈情境的單句填空題，常出現在出貨通知、倉儲管理紀錄、供應商採購合約與海關報關文件中。掌握以下技巧：
1.  **先看選項判斷詞性或句構**：若四個選項是同一字根的詞性變化，先找空格在句中的角色（修飾名詞、修飾動詞、當主詞補語…），不必先讀懂全句語意。
2.  **物流情境常見固定搭配**：ship ... to（將貨物運送至）、be responsible for（負責）、in transit（運送途中）、clear customs（通過海關）等，直接背誦搭配詞，不要用中文邏輯推導。
3.  **看到 be 動詞 + 空格** ➔ 先判斷時態或語態：`be + p.p.` 為被動（貨物「被」運送/檢驗），`be + V-ing` 為主動進行式。
4.  **分詞修飾貨物/文件時，判斷主動或被動**：貨物「被延誤」用過去分詞，供應商「延誤出貨」這個動作本身用現在分詞修飾其執行者。
5.  **子句連接詞先看空格後方是名詞還是完整子句**：Due to/Given 後接名詞片語，Although/Once 後接主詞+動詞的完整子句。
