## 題目描述 (中文摘要)
給一個 `m x n` 的整數矩陣 `matrix`，具備兩個性質：
- 每一列 (row) 由左到右**非遞減**排序。
- 每一列的第一個數**嚴格大於**上一列的最後一個數。

給定 `target`，若它存在於矩陣中回傳 `true`，否則回傳 `false`。題目要求時間複雜度 $O(\log(m \cdot n))$。

限制：`1 <= m, n <= 100`，`-10^4 <= matrix[i][j], target <= 10^4`。

範例：
```
matrix = [[ 1,  3,  5,  7],
          [10, 11, 16, 20],
          [23, 30, 34, 60]]

輸入：target = 3   輸出：true
輸入：target = 13  輸出：false
```

## 思路總覽 (Overview & Interview Plan)

### 中文解題計畫
兩個性質合起來，代表把矩陣逐列接起來就是一條**完整排序**的一維陣列，所以可以直接對整個矩陣做一次二分搜尋。
1. **演算法選擇**：採用 **二分搜尋 (Binary Search)**，在虛擬的一維索引 `0 ~ m*n-1` 上搜尋，不真的建立新陣列。
2. **具體步驟**：
   - 設 `lo = 0`、`hi = m * n - 1`。
   - 每輪取 `mid`，用 `row, col = divmod(mid, n)` 換回二維座標（`n` 是**欄數**）。
   - 命中就回傳 `true`；值太小就往右半找，值太大就往左半找。
   - 區間為空仍沒找到，回傳 `false`。
   - 另一種等價做法是「兩段式」：先二分找出 `target` 可能所在的那一列，再對那一列二分。

### English Interview Plan
Determine whether `target` exists in a matrix whose rows, read in order, form one sorted sequence.
1. **Strategy**: Treat the matrix as a virtual sorted array of length `m * n` and run a single binary search over it, giving $O(\log(mn))$ time with $O(1)$ extra space.
2. **Execution**:
   - **Initialization**: `lo = 0`, `hi = m * n - 1`.
   - **Iterative Step**: Map `mid` back to `(mid // n, mid % n)`, compare the value with `target`, and discard the half that cannot contain it.
   - **Key Insight**: Because each row starts strictly after the previous row ends, the row-major order of all cells is globally sorted, so index arithmetic is all we need — no extra array.

## 演算法詳解

暴力解是掃過所有格子，$O(mn)$；逐列各做一次二分是 $O(m \log n)$。兩者都沒有用到「列與列之間也有序」這個條件。一旦把矩陣看成一維排序陣列，問題就退化成 704. Binary Search 的標準模板，唯一多出來的工作是索引換算：

$$\text{index} = row \cdot n + col \quad\Longleftrightarrow\quad row = \lfloor \text{index} / n \rfloor,\ col = \text{index} \bmod n$$

### 狀態變化 (State Transitions)
以題目範例矩陣為例（`m = 3`、`n = 4`，虛擬陣列長度 12）。

**target = 3（存在）：**

| 輪次 | lo | hi | mid | (row, col) | 值 | 動作 |
|---|---|---|---|---|---|---|
| 1 | 0 | 11 | 5 | (1, 1) | 11 | 11 > 3，`hi = 4` |
| 2 | 0 | 4 | 2 | (0, 2) | 5 | 5 > 3，`hi = 1` |
| 3 | 0 | 1 | 0 | (0, 0) | 1 | 1 < 3，`lo = 1` |
| 4 | 1 | 1 | 1 | (0, 1) | 3 | 命中，回傳 `true` |

**target = 13（不存在）：**

| 輪次 | lo | hi | mid | (row, col) | 值 | 動作 |
|---|---|---|---|---|---|---|
| 1 | 0 | 11 | 5 | (1, 1) | 11 | 11 < 13，`lo = 6` |
| 2 | 6 | 11 | 8 | (2, 0) | 23 | 23 > 13，`hi = 7` |
| 3 | 6 | 7 | 6 | (1, 2) | 16 | 16 > 13，`hi = 5` |
| 結束 | 6 | 5 | — | — | — | `lo > hi`，回傳 `false` |

注意第 2 輪的 `mid = 8` 跨到了第 2 列的開頭 `(2, 0)`：一維視角下列與列之間沒有邊界，這正是這個解法能一次搜完整個矩陣的原因。

兩段式的做法對 `target = 13` 則是：先在各列的 `[首, 尾]` 區間上二分，`mid = 1` 時 `10 <= 13 <= 20`，鎖定第 1 列；再對 `[10, 11, 16, 20]` 二分，`11 < 13` → 右移、`16 > 13` → 左移，區間清空，回傳 `false`。

## 程式碼實作

### 攤平成一維二分 (Flatten)

```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        m, n = len(matrix), len(matrix[0])
        lo, hi = 0, m * n - 1

        while lo <= hi:
            mid = (lo + hi) // 2
            # 一列有 n 個元素，所以要除以欄數 n 才能換回 (row, col)
            row, col = divmod(mid, n)
            val = matrix[row][col]

            if val == target:
                return True
            if val < target:
                lo = mid + 1
            else:
                hi = mid - 1

        return False
```

### 兩段式二分 (Two-phase)

```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        m, n = len(matrix), len(matrix[0])

        # 第一段：找出 [首, 尾] 範圍涵蓋 target 的那一列
        top, bot = 0, m - 1
        while top <= bot:
            mid = (top + bot) // 2
            if target < matrix[mid][0]:
                bot = mid - 1
            elif target > matrix[mid][-1]:
                top = mid + 1
            else:
                break

        # 迴圈是因為區間清空才結束，代表 target 落在兩列之間或超出整個矩陣
        if top > bot:
            return False

        # 第二段：在鎖定的那一列做標準二分
        row = matrix[mid]
        lo, hi = 0, n - 1
        while lo <= hi:
            c = (lo + hi) // 2
            if row[c] == target:
                return True
            if row[c] < target:
                lo = c + 1
            else:
                hi = c - 1

        return False
```

兩個版本複雜度相同。Flatten 程式碼較短、只有一個迴圈；兩段式的好處是每一步都在真實的列/欄上操作，比較不會在 `divmod` 上出錯，也更容易改寫成「只知道每列首尾」的變形。

## 正確性說明

1. **不重複 (No Redundancy)**：每一輪都把搜尋區間縮小到嚴格更小的 `[lo, mid-1]` 或 `[mid+1, hi]`，同一個索引不會被檢查兩次。
2. **不遺漏 (Completeness)**：迴圈不變式是「若 `target` 存在，它的一維索引一定在 `[lo, hi]` 內」。因為整個 row-major 序列是排序的，`val < target` 時 `mid` 左邊（含 `mid`）全都小於 `target`，可以安全捨棄；`val > target` 同理。區間清空時就代表不存在。
3. **邊界條件**：
   - 限制保證 `m, n >= 1`，不需要處理空矩陣；但若改用在沒有這個保證的場合，`matrix[0]` 會先出錯，要先判斷。
   - `1 x 1` 矩陣：`lo = hi = 0`，只比一次。
   - 單列 (`m = 1`) 或單欄 (`n = 1`)：`divmod(mid, n)` 分別退化成 `(0, mid)` 與 `(mid, 0)`，照樣正確。
   - `target` 小於 `matrix[0][0]` 或大於 `matrix[-1][-1]`：`hi` 一路往左或 `lo` 一路往右，最後區間清空回傳 `false`，不會越界。

---

## 複雜度分析

- **Time Complexity**: $O(\log(m \cdot n))$
  - 其中 $m$ 為列數、$n$ 為欄數，一維虛擬陣列長度為 $mn$，每輪砍半。
  - 最好情況 $O(1)$：第一個 `mid` 就命中；最壞情況 $O(\log(mn))$：`target` 不存在或位於最後才檢查到的位置。
  - 兩段式是 $O(\log m + \log n)$，由 $\log m + \log n = \log(mn)$ 可知兩者等價。
- **Space Complexity**: $O(1)$
  - 只用了幾個索引變數；沒有真的把矩陣攤平成新陣列（那樣會變成 $O(mn)$ 空間，也讓時間退化成 $O(mn)$）。

---

## 常見誤區

1. **索引換算除以列數 `m`**：正確是 `row = mid // n`、`col = mid % n`，`n` 是欄數（每列的長度）。方陣測不出來，`3 x 4` 的範例一用 `m` 就會換到錯的格子甚至越界。
2. **真的建一個攤平陣列再二分**：`flat = [x for r in matrix for x in r]` 本身就是 $O(mn)$，二分省下的時間全被建陣列吃掉，也不符合題目要求的 $O(\log(mn))$。
3. **跟 240. Search a 2D Matrix II 搞混**：240 只保證每列、每欄各自排序，列與列之間沒有「首大於上一列尾」的關係，整體不是排序序列，不能一次二分，要用右上角出發的階梯搜尋 (Staircase Search)。反過來，在 74 用階梯搜尋雖然答案正確，但只有 $O(m + n)$，沒達到題目要求。
4. **兩段式第一段只比每列開頭**：例如寫成「`matrix[mid][0] <= target` 就鎖定這一列」，在範例找 `target = 60` 時，第一輪 `mid = 1`、`10 <= 60` 就鎖定第 1 列，但 60 其實在第 2 列，結果回傳 `false`。首元素 `<= target` 只代表答案在這列**或更下面**，要同時比較首與尾——小於首往上、大於尾往下、否則鎖定——才能確定就是這一列。
5. **兩段式忘記處理第一段沒找到**：第一段區間清空時 `mid` 仍停在最後檢查的列，若不先判斷 `top > bot` 就直接進第二段，雖然不會回傳錯誤答案，但多做了一次無意義的搜尋，也讓程式意圖不清楚。

## 延伸思考

### 只知道每列首尾的情況
兩段式其實只用到「每列首尾」來定位列，這讓它可以推廣到列長度不一、或資料存在外部儲存（每次只能讀一列）的場景：先用每列的首元素做索引，二分出列，再只載入那一列。資料庫的 B-Tree 索引與分頁也是同樣「先找區塊、再找區塊內位置」的思路。

### 從「找值」到「找邊界」
本題只問存在與否。若改成「回傳第一個 `>= target` 的位置」，就是 lower bound，迴圈條件與更新方式要改成 `lo < hi`、`hi = mid` 的版本，這是後面 [[153. Find Minimum in Rotated Sorted Array - 二分法邊界差異]] 會碰到的另一套模板。

## 小結

這題屬於「把多維結構映射回一維排序序列」的二分搜尋題，關鍵在辨認出全域有序，再用索引換算避免額外空間。

**核心觀念：**
- 「每列排序 + 列首大於上一列尾」等價於 row-major 全域排序，可以把矩陣當成長度 $mn$ 的一維陣列。
- 一維索引換二維座標用 `divmod(mid, n)`，除數是欄數。
- 兩段式（先找列、再找欄）複雜度相同，適合只能取得列首尾資訊的變形。
