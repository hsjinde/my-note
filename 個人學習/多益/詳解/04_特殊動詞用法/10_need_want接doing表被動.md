# 10_need_want接doing表被動 - 詳細解答

## 題目 1：need + V-ing 表被動
**答案**: B

**詳細解析**:
主詞是 the aging server（事物），而非人，因此 need 後面接 V-ing 表示「被…」的被動意義，等於 needs to be upgraded。(A) upgrade 是原形動詞，不能直接接在 needs 後面；(C) upgraded 若視為過去分詞，前面缺少 be 動詞，句型不完整；(D) to upgrading 文法上不存在這種搭配。

**相關文法點**:
對應正文「1. 句型公式」與「2. 為什麼是被動意義？主詞是關鍵」。

**相似題型提醒**:
只要看到「事物 + need + 空格」，先判斷主詞是不是事物，是的話優先選 V-ing。

## 題目 2：want + V-ing 表被動
**答案**: C

**詳細解析**:
主詞 several clauses（合約條款）是事物，want 在此不是「想要」而是「需要」的口語用法，後面接 V-ing 表示被動，意思是「這些條款需要被修改」。(A)(D) 文法形式不符合此句型；(B) revise 為原形動詞，不能直接接在 want 後面。

**相關文法點**:
對應正文「3. 三個常考動詞的細微差異」中關於 want + V-ing 的說明。

**相似題型提醒**:
want 表「需要」時常見於較口語的商業書信中，考生容易誤以為 want 只能接不定詞，需特別留意。

## 題目 5：人當主詞時 need + to V（非被動句型）
**答案**: B

**詳細解析**:
主詞 Ms. Alvarez 是「人」，不是事物，因此 need 後面不能用 V-ing 表被動意義（她不是「被學習」），而應接一般不定詞 to V，表示「她需要去學習」。這是本節「常見混淆點」特別強調的陷阱：主詞是人時，need 只能接 to V。

**相關文法點**:
對應正文「2. 為什麼是被動意義？主詞是關鍵」中「人當主詞」的範例說明。

**相似題型提醒**:
只要主詞換成人名或人稱代名詞，就要立刻切換成 to V 的判斷邏輯，不能沿用「事物 + need + Ving」的公式。

## 題目 8：merit + V-ing 表被動（類比 need/want）
**答案**: A

**詳細解析**:
merit 作動詞時意為「值得」，其後接 V-ing 也可比照 need/want 表示被動意義，等於 merits being reworded 的意思（實際上不用 being，直接用 V-ing），即「這份腳本值得被重新措辭」。(B) 原形動詞不可用；(C)(D) 形式不符。

**相關文法點**:
對應正文「補充秒絕公式」第 11 條「與 deserve 的類比」，merit 與 deserve 用法相近。

**相似題型提醒**:
deserve、merit 這類「值得」語意的動詞，後面接 V-ing 表被動的邏輯與 need/want 完全一致，可以互相類推記憶。
